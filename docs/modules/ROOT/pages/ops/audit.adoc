= 감사 로그
:toc: macro
:toclevels: 2

**감사 로그** 화면은 관리 작업의 기록을 한곳에서 보여 줍니다 — 누가 언제 사용자 · 설정 · 권한을 바꿨는지, 어떤 요청이
권한이 없어 거부됐는지, 운영 작업(닫힌 알림 정리 등)을 누가 했는지. 사용자 관리 · 설정 · 권한 관리 화면의 *변경 이력* 단추와
같은 기록을 범주 · 작업자 · 기간으로 걸러 봅니다.

toc::[]

== 시작하기 전에

=== 메뉴 위치

좌측 사이드바의 **관리 → 감사 로그** (`/dashboard/audit`) 로 들어갑니다.

=== 누가 볼 수 있나요

[cols="1,3"]
|===
| 작업 | 할 수 있는 사람

| 감사 로그 화면 보기
| 관리자, 그리고 기능 권한 *관리 감사 로그 조회* (`audit.view`, 미설정 시 관리자만)를 허용받은 역할
|===

`audit.view` 만 받은 역할은 사용자 관리 · 설정 · 권한 관리 메뉴를 열 수 없어도 이 화면에서 모든 범주의 기록을 봅니다.
권한을 주는 방법은 xref:ops/permissions.adoc#_관리_기능_위임[권한 관리 → 관리 기능 위임] 을 보세요.

NOTE: MCP 배포의 감사 이벤트(도구 호출 인자 포함)는 이 화면에 나오지 않습니다. 그 기록은 MCP Server 의 배포 상세에서
배포 소유자와 관리자만 봅니다.

== 화면 사용

[cols="1,3",options="header"]
|===
| 항목 | 설명

| 범주
| *전체 범주* · *사용자 관리* · *설정* · *권한 관리* · *운영 작업*. *권한 관리* 에는 메뉴 · 기능 권한 · 보기 전용 · 역할 변경과
  *권한 거부*(403) 기록이 함께 들어 있습니다.
| 작업자 아이디
| 그 사용자가 한 작업만 봅니다. 입력하고 Enter 를 누르거나 입력란을 벗어나면 적용됩니다.
| 기간
| 시작 날짜부터 끝 날짜까지(끝 날짜 포함, 브라우저 시간대 기준)의 기록만 봅니다. 한쪽만 넣어도 됩니다.
| 검색
| 대상 · 요약 · 작업자의 일부로 찾습니다.
|===

목록은 최신순이고 한 쪽에 20건씩 보입니다. 행을 누르면 바뀐 항목(이전 → 이후)과 요청한 IP 가 펼쳐집니다.
비밀번호 · 비밀값 · 전화번호는 값 없이 "(변경됨)"으로만 남습니다.

권한 거부 기록이 어떤 요청에 남는지는 xref:ops/permissions.adoc#_변경_이력[권한 관리 → 변경 이력] 을 보세요.
