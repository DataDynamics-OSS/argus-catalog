= 임베딩 운영
:toc: macro
:toclevels: 2

**임베딩**은 데이터셋·용어 같은 메타데이터를 숫자 벡터로 바꿔 두는 작업입니다. 임베딩을 켜 두면
xref:ops/search.adoc[검색] 에서 글자가 달라도 뜻이 비슷한 항목을 찾는 **시맨틱(의미) 검색**이 동작합니다.

이 문서는 관리자가 화면에서 임베딩을 켜고, 백필(일괄 임베딩)하고, 모델을 바꾸는 순서대로 설명합니다.
프로바이더 설치·에어갭 배포·DB 스키마 같은 심화 내용은 xref:ops/embedding-advanced.adoc[임베딩 — 고급 설정] 에 있습니다.

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **시맨틱 검색 켜기·끄기** — 스위치 하나로 켜고 끄며, 재시작이 필요 없습니다.
* **백필** — 기존 데이터셋과 용어집 · AI Agent · API · MCP 서버를 한꺼번에 임베딩합니다.
* **자동 임베딩** — 새로 만들거나 고친 항목을 바로 임베딩해 곧장 검색되게 합니다.
* **모델 바꾸기** — 다른 384 차원 모델로 바꾸고 다시 임베딩합니다.
* **현황 보기** — 커버리지(임베딩된 비율)를 확인합니다.

=== 먼저 알아 둘 용어

[cols="1,3",options="header"]
|===
| 용어 | 뜻

| 프로바이더(제공자)
| 텍스트를 벡터로 바꾸는 엔진입니다. Local(sentence-transformers, 기본) · Ollama · OpenAI 중 하나를 고릅니다.
| pgvector
| 벡터를 저장하고 검색하는 PostgreSQL 확장입니다. 어떤 프로바이더를 쓰든 필요합니다.
| 백필
| 저장된 항목 전체를 한꺼번에 임베딩하는 작업입니다.
| 커버리지
| 전체 데이터셋 중 임베딩된 비율입니다.
| 384 차원
| 벡터 저장 컬럼이 `vector(384)` 로 고정되어 있어, 384 차원 모델만 쓸 수 있습니다.
|===

[cols="1,2,3",options="header"]

| 관리 → 설정 → AI → 임베딩 | `/dashboard/settings?tab=embedding` | 켜기·끄기, 제공자·모델, 백필·삭제, 상태 확인

[cols="3,1,1",options="header"]

| 작업 | 로그인 사용자 | 관리자

| 시맨틱 검색 사용, 임베딩 통계 조회 | ✓ | ✓

NOTE: 데이터베이스에 pgvector 확장이 있어야 합니다. 스키마 DDL(`argus-catalog-postgresql.sql`)이 만들어 주며,
없을 때 설치하는 법은 xref:ops/embedding-advanced.adoc#_pgvector_설치[pgvector 설치] 를 보세요.

== 시맨틱 검색 켜기

. **관리 → 설정 → AI → 임베딩** 을 엽니다.
. **시맨틱 검색 활성화** 스위치를 켭니다.
. **제공자**와 **모델**을 고릅니다. 기본값은 `Local (sentence-transformers)` 와 다국어 모델 `paraphrase-multilingual-MiniLM-L12-v2` 이며, 한국어·영어가 섞인 메타데이터에 알맞습니다.
. **연결 테스트** 로 응답 시간 · 차원 · 모델을 확인합니다. 처음에는 모델을 내려받느라 수십 초 걸릴 수 있습니다. 연결 테스트는 설정을 저장하지 않습니다.
. **저장** 을 누릅니다. 저장하면 프로바이더가 재초기화됩니다.

image::ops-embedding/settings.png[임베딩 설정, 800]

화면 그림과 함께 보는 단계별 안내는 xref:ops/search.adoc#_시맨틱_검색_켜기_관리자[검색 → 시맨틱 검색 켜기] 에도 있습니다.

NOTE: 임베딩을 켜지 않은 설치에서 모델이 예전 기본값 `all-MiniLM-L6-v2` 그대로라면, 서버가 시작될 때 다국어 모델로 바뀝니다.
이미 임베딩을 켜서 쓰고 있거나 다른 모델을 고른 설치는 그대로 둡니다.

== 백필로 한꺼번에 임베딩하기

. **임베딩 관리** 카드의 **전체 데이터셋 백필** 을 누릅니다.
. 끝나면 `N건 임베딩, S건 건너뜀, E건 오류 (총 T건)` 알림이 뜹니다.
. **임베딩 상태** 카드에서 **커버리지**를 확인합니다.

이미 임베딩한 항목 중 원문과 프로바이더 · 모델이 모두 같은 항목은 건너뜁니다(중복 방지). 그래서 백필은 여러 번 눌러도 안전합니다.

== 새 데이터를 자동으로 임베딩하기

임베딩은 기본적으로 백필로 한꺼번에 만듭니다. **쓰기 시 자동 임베딩**(`embedding_auto_on_write`, 기본 꺼짐)을 켜고 저장하면
데이터셋을 생성하거나 수정할 때도 **비동기로 자동 임베딩** 됩니다. 끄면 새 데이터는 다음 백필 때 임베딩됩니다.

[[_4_모델_프로바이더_바꾸기]]
== 모델 · 프로바이더 바꾸기

모델이나 프로바이더가 다르면 같은 384 차원이라도 벡터 공간이 달라 다시 임베딩해야 합니다.
저장된 임베딩에는 원문(`source_text`)과 함께 **프로바이더 · 모델 이름**이 기록되어 있고, 백필은 둘 중 하나라도 다르면
그 데이터셋을 다시 임베딩합니다. 그래서 절차는 간단합니다.

. 새 모델(384 차원)을 고르고 **저장** 합니다.
. **연결 테스트** 로 응답 시간 · 차원 · 모델을 확인합니다.
. **전체 데이터셋 백필** 을 누릅니다. 이전 모델로 만든 임베딩이 모두 새 모델로 다시 만들어집니다.

미리 **모든 임베딩 삭제** 를 할 필요는 없습니다. 삭제하면 백필이 끝날 때까지 시맨틱 검색 결과가 비므로,
임베딩을 완전히 비우고 싶을 때만 쓰세요.

고를 수 있는 384 차원 모델은 다음과 같습니다.

[cols="2,1,2",options="header"]
|===
| 모델 | 한국어 | 비고

| `paraphrase-multilingual-MiniLM-L12-v2` (Local, 기본) | O | 470 MB, 한국어·영어 혼용 메타데이터에 적합
| `all-MiniLM-L6-v2` (Local) | △ | 80 MB, 영문 위주 경량
| `bge-small-en-v1.5` (Local) | X | 130 MB, 영문 고품질
| `all-minilm` (Ollama) | — | 별도 Ollama 서버 필요
|===

IMPORTANT: 384 차원이 아닌 모델(예: `bge-m3` 1024 차원, OpenAI `text-embedding-3-small` 1536 차원,
Ollama `nomic-embed-text` 768 차원)은 설정 저장 단계에서 **422** 로 거부되고 기존 설정이 그대로 유지됩니다.

====
Local 프로바이더 설치(CPU/GPU), Ollama · OpenAI 설정, 에어갭 환경에 모델 옮기기, MTEB 품질 비교는

== 끄기 · 임베딩 비우기

* **시맨틱 검색 활성화** 를 끄고 저장하면 재시작 없이 키워드 검색으로 돌아갑니다. 만든 임베딩은 남아 있어, 다시 켜면 그대로 씁니다.
* **모든 임베딩 삭제** 는 저장된 임베딩을 모두 지웁니다. 다시 쓰려면 백필을 실행해야 합니다.

== 자주 묻는 질문

[qanda]
모델(프로바이더)을 바꾼 뒤 검색 결과가 이상합니다.::
  **전체 데이터셋 백필** 을 한 번 실행하세요. 모델이 바뀐 데이터셋을 다시 임베딩합니다. <<_모델_프로바이더_바꾸기>> 참고.

`ERROR: type "vector" does not exist` 가 납니다.::
  pgvector 확장이 설치되지 않았습니다. 슈퍼유저로 활성화합니다.
+
[source,bash]
----
sudo -u postgres psql -d argus_catalog \
  -c "CREATE EXTENSION IF NOT EXISTS vector;"
----

`RuntimeError: sentence-transformers is required` 가 납니다.::
  Local 프로바이더에서만 납니다. `pip install "sentence-transformers>=3.0.0"` 으로 설치하세요. OpenAI / Ollama 만 쓰면 설치하지 않아도 됩니다.

`OSError: Can't load model 'paraphrase-multilingual-MiniLM-L12-v2'` 가 납니다(인터넷 없는 환경).::
  모델을 미리 내려받아 로컬 경로를 지정해야 합니다. xref:ops/embedding-advanced.adoc#_에어갭_배포[에어갭 배포] 를 보세요.

`torch.cuda.OutOfMemoryError` 가 납니다.::
  `export CUDA_VISIBLE_DEVICES=""` 로 CPU 모드를 강제하거나, 더 작은 모델(`all-MiniLM-L6-v2`, 80 MB · 영문 위주)을 쓰세요.

OpenAI 모델을 저장하면 422 오류가 납니다.::
  OpenAI 임베딩 모델은 1536 · 3072 차원이라 `vector(384)` 컬럼에 저장할 수 없습니다. 384 차원 Local · Ollama 모델을 쓰세요.

[[_임베딩_rest_api]]
== 부록: REST API

[cols="1,3,2",options="header"]
|===
| Method | Path | 권한

| GET | `/api/v1/settings/embedding` | 관리자
| PUT | `/api/v1/settings/embedding` | 관리자
| POST | `/api/v1/settings/embedding/test` | 관리자
| GET | `/api/v1/catalog/search/embeddings/stats` | 로그인 사용자
| POST | `/api/v1/catalog/search/embeddings/backfill` | 관리자
| DELETE | `/api/v1/catalog/search/embeddings` | 관리자
|===

[source,bash]
----
# 관리자 토큰 받기
TOKEN=$(curl -s -X POST http://<server>:4600/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"<관리자>","password":"<비밀번호>"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

# 커버리지 통계 (로그인 사용자)
curl http://<server>:4600/api/v1/catalog/search/embeddings/stats \
  -H "Authorization: Bearer $TOKEN"
# → {"total_datasets": 135, "embedded_datasets": 120, "coverage_pct": 88.9,
#    "provider": "local", "model": "paraphrase-multilingual-MiniLM-L12-v2", "dimension": 384}

# 전체 백필 (관리자)
curl -X POST http://<server>:4600/api/v1/catalog/search/embeddings/backfill \
  -H "Authorization: Bearer $TOKEN"

# 전체 삭제 (관리자 — 임베딩을 비우고 처음부터 다시 만들 때)
curl -X DELETE http://<server>:4600/api/v1/catalog/search/embeddings \
  -H "Authorization: Bearer $TOKEN"
----
