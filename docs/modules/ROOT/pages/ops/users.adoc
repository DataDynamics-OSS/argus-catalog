= 사용자 관리
:toc: macro
:toclevels: 2

**사용자 관리** 화면에서는 Argus Catalog 에 로그인하는 계정을 만들고, 각 계정에 역할을 줍니다.
역할별로 어떤 메뉴와 기능을 쓸 수 있는지는 xref:ops/permissions.adoc[권한 관리] 에서 정하고,
로그인 방식(Local / Keycloak)이나 토큰 정책 같은 인증 자체는 xref:ops/authentication.adoc[인증] 에서 다룹니다.

이 문서는 처음 사용하는 분을 기준으로 화면 순서대로 설명합니다.
**고급 사용자** 상자는 몰라도 사용에 지장이 없는 심화 내용이니 처음에는 건너뛰어도 됩니다.

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **사용자 찾기** — 이름 · 이메일 · 소속으로 검색하고 상태 · 역할 · 소속으로 걸러 봅니다.
* **사용자 추가** — 계정을 만들고 역할을 줍니다 (Local 모드).
* **수정 · 비밀번호 변경 · 잠금 해제** — 계정 정보를 고치고 잠긴 계정을 풉니다.
* **활성화 · 비활성화 · 삭제** — 여러 사용자를 한꺼번에 활성화 · 비활성화하거나 계정을 지웁니다.
* **변경 이력 확인** — 누가 언제 무엇을 바꿨는지 봅니다.

=== 먼저 알아 둘 용어

[cols="1,3",options="header"]
|===
| 용어 | 뜻

| 역할 | 사용자에게 주는 권한 묶음입니다. 관리자 · 슈퍼유저 · 사용자 세 가지가 있습니다. 아래 <<_역할>> 을 참고하세요.
| 활성 / 비활성 | 비활성 사용자는 로그인할 수 없습니다.
| Local / Keycloak | 로그인 방식입니다. Local 은 이 화면에서 계정을 만들고, Keycloak 은 Keycloak 에서 만듭니다.
|===

=== 메뉴 위치

좌측 사이드바의 **관리 → 사용자 관리** (`/dashboard/users`) 로 들어갑니다.

=== 누가 무엇을 할 수 있나요

[cols="3,1,1",options="header"]
|===
| 작업 | 일반 사용자·슈퍼유저 | 관리자

| 사용자 관리 화면 보기 · 변경 | × | ✓
|===

관리 메뉴는 `argus-admin` 역할을 가진 관리자만 볼 수 있고, 권한 관리에서도 다른 역할에 열 수 없습니다.

== 사용자 목록

image::ops-users/list.png[사용자 목록, 900]

목록에는 사용자명 · 이름 · 이메일 · 소속 · 소속 부서 · 전화번호 · 상태 · 생성일 · 마지막 로그인 · 역할이 나옵니다.
머리글의 화살표로 정렬하고, 아래쪽에서 페이지당 행 수와 페이지를 바꿉니다.
상태는 **활성** / **비활성** 배지로 보입니다.

[cols="1,3",options="header"]
|===
| 도구 | 설명

| 검색창
| 이름 · 이메일 · 소속으로 찾습니다. 입력 후 **검색** 을 누르거나 Enter 를 칩니다.
| **상태** · **역할** · **소속** 필터
| 활성/비활성, 관리자/슈퍼유저/사용자, 소속별로 좁혀 봅니다. 여러 값을 함께 고를 수 있습니다.
| **초기화**
| 검색어와 필터를 모두 지웁니다.
| **변경 이력**
| 사용자 관리에서 일어난 변경(생성 · 수정 · 삭제 · 상태 변경 등)을 최신순으로 봅니다. 아래 <<_사용자_변경_이력>> 을 참고하세요.
| **작업**
| 선택한 사용자를 일괄 활성화 · 비활성화하거나 새 사용자를 추가합니다.
|===

== 사용자 추가

. **작업 → 추가** 를 누릅니다.
+
image::ops-users/actions-menu.png[작업 메뉴, 900]
. 사용자 추가 대화상자에 아래 항목을 넣습니다.
+
image::ops-users/add-dialog.png[사용자 추가, 900]
. 저장합니다.

[cols="1,3",options="header"]
|===
| 항목 | 설명

| 이름 · 성 (필수)
| 화면에 표시되는 이름입니다.
| 사용자명 (필수)
| 로그인 아이디입니다. 만든 뒤에는 바꿀 수 없습니다.
| 소속 · 소속 부서
| 목록의 소속 필터와 AI Agent 등록 시 부서 기본값으로 쓰입니다.
| 이메일 (필수)
| 알림 메일 수신 주소입니다.
| 전화번호
| 선택 항목입니다. 변경 이력에는 값 없이 "(변경됨)"만 남습니다.
| 역할 (필수)
| 관리자 · 슈퍼유저 · 사용자 중 하나입니다. 아래 <<_역할>> 을 참고하세요.
| 비밀번호 · 비밀번호 확인 (필수)
| 최초 비밀번호입니다.
|===

NOTE: **추가** 는 인증 방식이 **Local** 일 때만 메뉴에 나타납니다. **Keycloak** 모드에서는 계정을 Keycloak 에서
만들며, 처음 로그인할 때 Argus Catalog 에 사용자 정보가 생깁니다.

== 사용자 수정 · 비밀번호 변경 · 삭제

각 행 오른쪽의 `⋯` 버튼을 누르면 그 사용자에 대한 작업 메뉴가 열립니다.

image::ops-users/row-actions.png[행 작업 메뉴, 900]

[cols="1,3",options="header"]
|===
| 메뉴 | 설명

| **수정**
| 이름 · 소속 · 이메일 · 전화번호 · 역할을 바꿉니다. 사용자명은 바꿀 수 없습니다.
| **비밀번호 변경**
| 관리자가 새 비밀번호를 지정합니다 (Local 모드).
| **잠금 해제**
| 로그인에 5회 연속 실패해 15분 동안 잠긴 계정을 바로 풀어 줍니다. 잠긴 계정에만 보입니다 (Local 모드).
| **삭제**
| 계정을 영구 삭제합니다. 아래 주의 사항을 참고하세요.
|===

image::ops-users/edit-dialog.png[사용자 정보 수정, 900]

=== 삭제할 때 주의할 점

* **마지막 관리자 보호** — 활성 관리자가 한 명뿐이면 그 관리자는 삭제 · 비활성화 · 역할 강등을 할 수 없습니다.
* **소유 자산 이관** — 삭제할 사용자가 만든 데이터셋 · 모델 · AI Agent · MCP 배포 등 편집 권한이 아이디로 묶인
  자산이 있으면, 자산을 넘겨받을 활성 사용자를 지정해야 삭제됩니다.
  같은 아이디로 새 계정을 만들었을 때 이전 자산의 권한을 이어받지 않도록 하기 위한 규칙입니다.

[[_역할]]
== 역할

권한은 사용자에게 직접 주지 않습니다. 사용자에게 **역할**을 주고, 역할이 쓸 수 있는 메뉴와 기능은
xref:ops/permissions.adoc[권한 관리] 에서 정합니다.

.사용자 역할별 권한
image::diagrams/ops-users-01.png[사용자 역할별 권한,role="diagram"]

[cols="1,1,3",options="header"]
|===
| 화면 표시 | 역할 | 권한 범위

| 관리자
| `argus-admin`
| 모든 메뉴와 기능을 쓸 수 있습니다. 관리 메뉴(사용자 관리 · 설정 · 권한 관리)는 관리자만 씁니다.
| 슈퍼유저
| `argus-superuser`
| 권한 관리에서 허용한 메뉴와 기능을 씁니다.
| 사용자
| `argus-user`
| 권한 관리에서 허용한 메뉴와 기능을 쓰며, 본인이 만든 데이터셋 · 모델 · AI Agent 등은 수정할 수 있습니다.
|===

`argus-*` 역할이 **하나도 없는** 사용자는 로그인이 거부됩니다 (403).

[TIP]
.고급 사용자 — Keycloak 모드의 역할
====
Keycloak 모드에서는 위 역할이 Realm Role 로 매핑됩니다. 신규 사용자에게는 default role 로 `argus-user` 가
자동으로 부여되고, `argus-admin` / `argus-superuser` 는 수동으로 부여합니다.
자세한 절차는 xref:ops/authentication-advanced.adoc#_keycloak_수동_설정[인증 — 고급 설정 → Keycloak 수동 설정] 을 참고하세요.
그룹 단위 관리도 Keycloak Admin 콘솔에서 합니다.
====

[[_사용자_변경_이력]]
== 변경 이력

사용자 관리 · 설정 · 권한 관리 화면 오른쪽 위의 **변경 이력** 버튼은 그 화면에서 일어난 변경을 누가 · 언제 ·
무엇을 바꿨는지 최신순으로 보여 줍니다.

* 행을 누르면 바뀐 항목(이전 → 이후)이 펼쳐집니다.
* 검색창으로 대상 · 요약 · 작업자를 찾을 수 있습니다.
* 비밀번호 · 비밀값 · 전화번호는 값 없이 "(변경됨)"으로만 기록됩니다.

== 자주 묻는 질문

[qanda]
**작업** 메뉴에 **추가** 가 없습니다.::
  인증 방식이 Keycloak 입니다. 계정은 Keycloak 에서 만들고, 처음 로그인할 때 Argus Catalog 에 사용자 정보가 생깁니다.

사용자가 로그인할 수 없습니다.::
  계정이 **비활성** 인지, `argus-*` 역할이 하나도 없는지(403) 확인하세요.
  5회 연속 실패로 잠긴 경우 15분이 지나거나 행 메뉴의 **잠금 해제** 로 풀 수 있습니다(Local 모드).

관리자를 삭제하거나 강등할 수 없습니다.::
  활성 관리자가 한 명뿐이면 보호됩니다. 다른 관리자를 먼저 만드세요.

사용자를 삭제하려는데 넘겨받을 사용자를 고르라고 합니다.::
  그 사용자가 만든 자산이 있습니다. 자산을 넘겨받을 활성 사용자를 지정해야 삭제됩니다.
