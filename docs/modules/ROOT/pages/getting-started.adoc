= 시작하기

이 페이지는 설치 후 또는 발급받은 URL 로 Argus Catalog에 처음 접속하는 분을 위한
안내입니다. 로그인부터 첫 작업까지 차근차근 따라가 보겠습니다.

== 첫 작업 추천

처음이라면 다음 순서대로 진행하시면 카탈로그가 채워지는 과정을 자연스럽게 익힐 수
있습니다.

1. xref:catalog/platforms.adoc[플랫폼 등록] — 사내 DB · 데이터 레이크를 연결합니다.
2. *메타데이터 동기화* 실행 — 자동으로 데이터셋·스키마가 적재됩니다.
3. xref:catalog/datasets.adoc[데이터셋] 메뉴에서 적재 결과를 확인합니다.
4. xref:catalog/tags-glossary.adoc[태그 · 용어집] 으로 비즈니스 분류를 부착합니다.
5. xref:ops/search.adoc[검색] 에서 시맨틱 검색 동작을 확인합니다.
