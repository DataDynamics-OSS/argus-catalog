= 로컬 승격 (import)
:toc: macro
:toclevels: 2

다른 팀(peer)의 데이터셋을 이 카탈로그의 **1급 데이터셋** 으로 복사하는 기능입니다.
미러는 읽기 전용이지만, 가져온 데이터셋은 로컬에서 자유롭게 편집 · 검색하고 품질 · 변경 관리 같은 기능에도 쓸 수 있습니다.

이 문서는 처음 사용하는 분을 기준으로 화면 순서대로 설명합니다.
중간중간 나오는 **고급 사용자** 상자는 몰라도 사용에 지장이 없는 심화 내용이니 처음에는 건너뛰어도 됩니다.

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **로컬로 가져오기** — 원격 상세 화면에서 버튼 한 번으로 peer 데이터셋을 복사합니다.
* **출처 추적** — 가져온 데이터셋에 원본 위치가 속성으로 남습니다.
* **태그 · 용어집 연결** — 이름이 같은 로컬 태그 · 용어가 있으면 자동으로 연결합니다.

=== 알아 둘 점

* 가져온 데이터셋은 **가져온 시점의 1회 스냅샷** 입니다. 이후 peer 에서 바뀐 내용은 반영되지 않습니다(미러와 분리).
* 가져오려면 peer 에 닿을 수 있어야 하고 그 데이터가 노출돼 있어야 합니다. `PAUSED` 인 peer 의 데이터셋은 가져올 수 없습니다.

=== 누가 무엇을 할 수 있나요

로컬로 가져오기는 **관리자(admin)만** 할 수 있습니다. 일반 사용자에게는 원격 상세 화면에 버튼이 보이지 않습니다.

image::federation/detail-user-no-import.png[일반 사용자가 연 원격 상세 — 로컬로 가져오기 버튼 없음, 900]

== 로컬로 가져오기

. 통합 검색이나 탐색에서 peer 데이터셋의 원격 상세를 엽니다(xref:federation/browse-search.adoc#_원격_데이터셋_상세[원격 데이터셋 상세] 참고).
. 머리글 오른쪽의 **로컬로 가져오기** 를 누릅니다.
. "로컬 카탈로그로 가져오기" 확인 대화상자에서 **가져오기** 를 누릅니다.

image::federation/import-confirm.png[로컬 카탈로그로 가져오기 확인 대화상자, 900]

완료되면 탭 위에 "'<이름>' 을(를) 로컬 데이터셋으로 가져왔습니다." 안내가 뜹니다. 오른쪽 **로컬 데이터셋 열기 →** 로 만들어진 데이터셋으로 바로 이동할 수 있습니다.

image::federation/import-done.png[가져오기 완료 안내와 로컬 데이터셋 열기 링크, 900]

== 가져온 데이터셋 확인

가져온 데이터셋은 사이드바 > **데이터셋** 에서 다른 데이터셋처럼 찾을 수 있습니다.

* 데이터 소스 **Federation Imports**(유형 `federation`) 아래에 만들어집니다.
* **페더레이션** 태그가 붙어, 사이드바 > 태그에서 한눈에 구분 · 필터할 수 있습니다("페더레이션" 태그가 없으면 자동으로 만들어집니다).
* 스키마 · 샘플 탭도 원본과 같은 내용으로 채워집니다.

image::federation/import-local-copy.png[가져온 로컬 데이터셋 — Federation Imports 데이터 소스와 페더레이션 태그, 900]

=== 태그와 용어집

peer 태그를 그대로 가져오면 로컬 태그 목록이 어지러워지므로 **매칭만** 합니다.

* peer 태그는 **이름이 같은 로컬 태그가 이미 있을 때만** 연결하고, 없으면 새로 만들지 않습니다.
* 용어집(glossary)도 같은 방식으로 매칭만 합니다.
* 매칭 여부와 무관하게 원본 태그/용어 전체는 아래 출처 속성(`imported_tags` · `imported_glossary`)으로 보존합니다.

=== 출처(provenance)

가져온 데이터셋에는 다음 속성이 기록됩니다. 데이터셋 상세의 메타데이터(속성)에서 확인할 수 있습니다.

[cols="1,3",options="header"]
|===
| 속성 키 | 값
| `imported_from` | 원본 federated URN (`{식별 키}::{원격 URN}`)
| `imported_from_instance` | 원본 peer 의 식별 키
| `imported_tags` | 원본 peer 태그 전체(쉼표)
| `imported_glossary` | 원본 peer 용어 전체(쉼표)
|===

+
image::federation/import-duplicate.png[이미 가져온 데이터셋 오류, 900]

**로컬로 가져오기** 버튼이 없습니다.::
  관리자만 쓸 수 있습니다.

peer 에서 바뀐 내용이 가져온 데이터셋에 반영되지 않습니다.::
  가져온 데이터셋은 1회 스냅샷이라 이후 변경은 반영되지 않습니다. 최신 내용은 원격 상세에서 보세요.

두 카탈로그가 서로를 peer 로 등록하면 가져온 복사본이 되돌아가지 않나요?::
  되돌아가지 않습니다. 가져온 데이터셋(Federation Imports)은 이 인스턴스의 export 대상에서 항상 빠집니다.

[TIP]
.고급 사용자 — 내부 동작과 API
====
가져오기는 내부적으로 다음 순서로 동작합니다.

. peer 드릴다운으로 전체 메타데이터(스키마·태그·소유자·용어집·DDL·확장 메타데이터·샘플)를 받습니다.
. 전용 **"Federation Imports"** 데이터 소스를 찾거나 만들어 그 아래에 데이터셋을 만듭니다.
. 스키마 컬럼·소유자·확장 메타데이터를 복사하고, 샘플은 로컬 parquet 으로 저장합니다.
. 로컬 임베딩을 만들어 검색에 편입합니다.

.원격 자산을 로컬 데이터셋으로 가져오기
image::diagrams/federation-import-01.png[원격 자산을 로컬 데이터셋으로 가져오기,role="diagram"]

* **URN** — `federation-<id>.{식별 키}.{원격 경로}.dataset` 형태로 새로 발급되어 peer 사이에 충돌하지 않습니다.
* **중복 차단** — 같은 federated URN 을 다시 가져오면 `409` 로 거절합니다.
* **에코 방지** — 가져온 데이터셋(Federation Imports)은 이 인스턴스의 export 대상에서 항상 빠집니다.
* **API** — `POST /api/v1/federation/datasets/import` 에 `{"federated_urn": "<식별 키>::<원격 URN>"}` 을 보냅니다.
