= 인스턴스 관리
:toc: macro
:toclevels: 2

페더레이션 > **인스턴스 관리** 탭에서 연합 대상 peer(다른 팀의 Argus Catalog)를 등록 · 수정 · 삭제하고 연결 상태를 점검합니다.

이 문서는 처음 사용하는 분을 기준으로 화면 순서대로 설명합니다.
중간중간 나오는 **고급 사용자** 상자는 몰라도 사용에 지장이 없는 심화 내용이니 처음에는 건너뛰어도 됩니다.

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **peer 등록** — 다른 카탈로그의 주소와 서비스 토큰으로 연합 대상을 추가합니다.
* **상태점검** — peer 에 닿는지, 응답 시간과 버전을 확인합니다.
* **표시 정보 선택** — 원격 상세 화면에 보여 줄 항목만 고릅니다.
* **일시 중지** — 삭제하지 않고 잠시 연합에서 뺍니다.
* **가져오기 실행** — 행의 아이콘으로 가져오기 · 전체 재동기화 · 동기화 이력을 다룹니다(xref:federation/harvest.adoc[가져오기] 참고).

=== 메뉴 위치

**데이터 카탈로그 → 페더레이션** → **인스턴스 관리** 탭(`/dashboard/federation?tab=…`).

=== 누가 무엇을 할 수 있나요

이 탭과 모든 변경 작업은 **관리자(admin) 전용** 입니다. 일반 사용자에게는 탭이 보이지 않고, API 를 직접 호출해도 `403` 으로 거절됩니다.

=== peer 의 상태

등록하면 `ACTIVE` 로 운영하다가, 잠시 멈출 때는 `PAUSED` 로 바꾸고, 필요 없어지면 삭제합니다.

== 인스턴스 등록

처음에는 표에 "등록된 인스턴스가 없습니다." 가 보입니다.

image::federation/instances-empty.png[인스턴스 관리 탭 — 등록 전, 900]

. 오른쪽 위 **인스턴스 등록** 을 누르면 "인스턴스 등록" 대화상자가 열립니다.
. 아래 표의 항목을 채웁니다. 모드는 특별한 이유가 없으면 기본값 `HYBRID` 를 그대로 둡니다.
. (선택) 원격 상세에 보여 줄 항목을 줄이려면 <<_표시_정보_선택>> 을 합니다.
. **등록** 을 누릅니다.

image::federation/instance-register.png[인스턴스 등록 대화상자 — HYBRID 권장 모드, 900]

[cols="1,3",options="header"]
|===
| 항목 | 설명
| 식별 키 (instance_key) | 허브 안에서 peer 를 구분하는 키로, federated URN 의 앞부분이 됩니다. **영문 대소문자·숫자·`_`·`-`** 만 쓸 수 있고 전체에서 유일해야 합니다. 등록 후에는 바꿀 수 없습니다.
| 이름 | 화면에 표시할 이름입니다.
| Base URL | peer **백엔드** 의 루트 주소입니다(예: `http://catalog-team-b:4600`). `http://` 또는 `https://` 로 시작해야 하며, 끝의 `/` 는 자동으로 떼어집니다. 주소에 사용자 정보(`user:pass@`)는 넣을 수 없습니다.
| 모드 | `HYBRID`(권장, 기본값) · `HARVEST` · `LIVE`. 항목마다 한 줄 설명이 있고, 고른 모드의 설명이 아래에 표시됩니다(xref:federation/index.adoc#_연합_모드[연합 모드] 참고).
| 동기화 주기(초) | 스케줄러가 이 peer 를 가져오는 주기입니다. **최소 30초**, 기본 900초입니다.
| 서비스 토큰 | peer 의 export API 토큰입니다(선택). 비밀번호 입력란이며, 저장하면 암호화해 보관하고 화면이나 API 응답에 원문을 다시 보여 주지 않습니다.
| 설명 | 메모(선택)
|===

IMPORTANT: **Base URL** 은 프론트엔드 주소(예: `:3000`)가 아니라 카탈로그 **API** 를 가리켜야 합니다. peer 는 `/health` 와 `/api/v1/federation/export/*` 를 제공해야 합니다.

입력값은 **등록** 을 누를 때 이름 → Base URL → 주기 → 식별 키 형식 → 식별 키 중복 순서로 확인하고, 문제가 있으면 하나씩 안내합니다.

[cols="1,2",options="header"]
|===
| 상황 | 안내

| Base URL 형식이 틀림 | "Base URL 은 http:// 또는 https:// 로 시작해야 합니다."
| 주기가 30 미만 | "동기화 주기는 30초 이상의 정수여야 합니다."
| 식별 키에 허용되지 않는 문자 | "식별 키는 영문 대소문자, 숫자, _, - 만 사용할 수 있습니다."
| 이미 있는 식별 키 | "이미 사용 중인 식별 키입니다: <키>" (입력란 빨간 테두리)
|===

image::federation/instance-dup-key.png[이미 사용 중인 식별 키 안내, 900]

[TIP]
.고급 사용자 — 자기 자신 등록 막기
====
설정 `federation.public_base_url` 에 이 인스턴스의 공개 주소를 적어 두면, 같은 주소를 peer 로 등록하려 할 때 거절합니다.
====

=== 등록된 인스턴스 행

등록이 끝나면 표에 행이 생깁니다. 열은 인스턴스(이름 · 식별 키 · Base URL) · 모드 · 상태 · 주기 · 상태점검 · 작업입니다.

image::federation/tabs-admin.png[등록된 인스턴스 행과 작업 아이콘, 900]

행 오른쪽 작업 아이콘은 다음과 같습니다.

[cols="1,3",options="header"]
|===
| 아이콘 | 동작

| 가져오기 (증분) | 변경분을 가져옵니다. xref:federation/harvest.adoc[가져오기] 참고.
| 전체 재동기화 | 확인 후 전량을 다시 가져오고, peer 에서 사라진 데이터셋을 정리합니다.
| 동기화 이력 | 가져오기 실행 이력을 봅니다.
| 수정 | 인스턴스 수정 대화상자를 엽니다.
| 삭제 | 확인 후 인스턴스를 지웁니다.
|===

가져오기 두 아이콘은 `ACTIVE` 이면서 `HARVEST`/`HYBRID` 모드인 peer 에만 보입니다.

== 상태점검

. 행의 **점검** 을 누릅니다. peer 의 `/health` 를 호출해 도달성 · 지연 · 버전을 확인합니다.
. 결과를 확인합니다.
** 성공 — 초록 체크와 `지연(ms) · v버전`(예: `15ms · v0.5.0`)
** 실패 — 빨간 `불가 · 사유`(예: `HTTP 404`, `Connection refused`, 이름 해석 실패)

결과 글자를 누르면(툴팁 "다시 점검") 다시 점검합니다.

image::federation/health-ok.png[상태점검 성공 — 지연 시간과 peer 버전, 900]

image::federation/health-fail.png[상태점검 실패 — 불가와 사유, 900]

== 표시 정보 선택

이 허브의 원격 상세 화면에 **보여 줄** 항목만 고르는 기능입니다.

. 등록 · 수정 대화상자 아래 **표시 정보 선택** 의 **노출 항목 불러오기** 를 누릅니다.
. peer 가 제공하는 항목이 기본정보 · 스키마 · 거버넌스/관계 · 데이터 그룹별 체크리스트로 나옵니다.
. 보여 주지 않을 항목의 체크를 풉니다. 그룹마다 **전체 해제** / **전체 선택** 이 있고, 아래에 `25개 표시 / 25개 제공` 처럼 고른 수와 제공 수가 보입니다.
. 저장합니다.

image::federation/instance-capabilities.png[노출 항목 불러오기 — 그룹별 표시 정보 체크리스트, 900]

* 불러오지 않고 저장하면 peer 가 제공하는 항목이 전부 표시됩니다.
* 예를 들어 **샘플 데이터** · **DDL** · **오너** 를 해제하면 원격 상세에서 샘플 탭과 DDL · 오너 정보가 사라집니다. 샘플은 화면뿐 아니라 API 로도 제공하지 않고, 이미 받아 둔 미러 샘플도 다음 가져오기 때 정리됩니다.
* 서비스 토큰이 필요한 peer 인데 Base URL 을 바꿨다면, 토큰을 다시 입력하거나 먼저 저장한 뒤 불러오세요.

image::federation/display-fields.png[샘플 · DDL · 오너를 해제한 표시 정보 선택(22개 표시), 900]

NOTE: 이 설정은 **소비자(허브)** 쪽에서 보여 줄 항목을 고르는 것입니다. peer 가 처음부터 내보내지 않는 항목은
peer 의 **노출 설정** 에서 정합니다(xref:federation/governance.adoc[노출 거버넌스] 참고).

== 인스턴스 수정

**수정**(연필) 아이콘을 누르면 "인스턴스 수정" 대화상자가 열립니다. 등록 화면과 같지만 몇 가지가 다릅니다.

* **식별 키** 는 바꿀 수 없어 비활성으로 보입니다.
* **서비스 토큰 (변경 시에만 입력)** — 비워 두면 저장된 토큰을 그대로 유지합니다(placeholder "저장된 토큰 유지 (암호화 보관)"). 토큰을 없애려면 **저장된 토큰 제거** 를 체크합니다.
* **상태** — `ACTIVE` / `PAUSED` 를 고릅니다.

image::federation/instance-edit.png[인스턴스 수정 — 저장된 토큰 유지와 상태 선택, 900]

[[_일시_중지]]
=== 일시 중지 (PAUSED)

peer 점검 · 장애 등으로 잠시 연합에서 빼고 싶을 때는 삭제 대신 상태를 `PAUSED` 로 바꿉니다.
미러 데이터는 그대로 남아 있다가 `ACTIVE` 로 돌리면 다시 쓰입니다.

`PAUSED` 인 동안에는

* 행의 상태 배지가 회색 `PAUSED` 가 되고, 가져오기 아이콘이 사라집니다(동기화 이력 · 수정 · 삭제만 남음).
* 스케줄러가 가져오기를 건너뜁니다.
* 통합 검색 · 탐색 · cross-instance 리니지에서 빠지고, 원격 상세 · 로컬 가져오기도 할 수 없습니다.

image::federation/instance-paused.png[PAUSED 인스턴스 — 가져오기 아이콘 숨김, 900]

== 삭제

. 행의 **삭제**(빨간 휴지통)를 누릅니다.
. "인스턴스 삭제" 확인 대화상자에서 삭제를 확인합니다.

image::federation/instance-delete.png[인스턴스 삭제 확인 대화상자, 900]

WARNING: 인스턴스를 삭제하면 그 peer 에서 가져온 **미러 데이터셋·임베딩·리니지·가져오기 이력** 과 저장된 샘플 파일이 모두
함께 삭제되며, 되돌릴 수 없습니다. 원본 peer 의 실제 데이터와, 이 카탈로그로 이미 **로컬로 가져온** 데이터셋은 영향을 받지 않습니다.
잠시 빼려는 것이라면 삭제 대신 <<_일시_중지,일시 중지>> 를 쓰세요.

== 자주 묻는 질문

[qanda]
상태점검이 `HTTP 404` 로 실패합니다.::
  Base URL 이 프론트엔드 주소(예: `:3000`)를 가리키고 있을 가능성이 큽니다. 카탈로그 **백엔드(API)** 주소로 고치세요.

가져오기 아이콘이 보이지 않습니다.::
  `PAUSED` 상태이거나 `LIVE` 모드인 peer 입니다. 가져오기는 `ACTIVE` 이면서 `HARVEST`/`HYBRID` 모드인 peer 에만 있습니다.

수정할 때 서비스 토큰 칸이 비어 있습니다.::
  저장된 토큰은 다시 보여 주지 않습니다. 비워 두면 기존 토큰을 그대로 씁니다.

식별 키를 바꾸고 싶습니다.::
  등록 후에는 바꿀 수 없습니다. 새 식별 키로 다시 등록하세요.
