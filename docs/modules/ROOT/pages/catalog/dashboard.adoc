= 대시보드

대시보드는 로그인하면 가장 먼저 보이는 화면입니다. 카탈로그에 등록된 데이터 자산의 현황을 카드 · 차트 · 표로
한 장에 요약해 보여 줍니다. 보기만 하는 화면이라 따로 조작할 것은 없습니다.

.대시보드 요약 카드와 탐색 흐름
image::diagrams/catalog-dashboard-01.png[대시보드 요약 카드와 탐색 흐름,role="diagram"]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **규모 파악** — 데이터셋 · 데이터 소스 · 태그 · 용어집 · 소유자 수와 동기화 현황을 요약 카드로 봅니다.
* **분포 확인** — 데이터 소스 유형 · 환경별 분포와 데이터셋이 많은 데이터 소스를 차트로 봅니다.
* **추이 확인** — 최근 24시간 · 7일 · 30일 동안 새로 등록된 데이터셋 수를 봅니다.
* **메타데이터 채움 정도** — 스키마 필드 수 · 태그 수 상위 항목을 봅니다.
* **바로 이동** — 최근 수정된 데이터셋을 눌러 상세 화면으로 이동합니다.

=== 메뉴 위치

좌측 사이드바의 *데이터 카탈로그 → 대시보드* (`/dashboard`) 로 들어갑니다. 사이드바 맨 위의
*Argus Catalog* 를 눌러도 대시보드로 돌아오며, 로그인 직후에도 이 화면이 열립니다. 헤더 제목은
*데이터 카탈로그* 로 표시됩니다.

image::catalog-dashboard/dashboard.png[대시보드 첫 화면 — 요약 카드 · 분포 · 추이 차트, 900]

=== 누가 무엇을 할 수 있나요

[cols="1,3"]
|===
| 작업 | 할 수 있는 사람

| 대시보드 조회
| 로그인한 사용자 누구나. 로그인하지 않고 주소를 열면 로그인 화면으로 이동합니다.
| 표시되는 숫자
| 관리자와 일반 사용자 모두 *같은 값* 을 봅니다. 사용자별로 걸러 보여 주지 않는 카탈로그 전체 통계입니다.
|===

아래는 일반 사용자로 로그인한 화면입니다. 사이드바에 *관리* 그룹이 없는 것 말고는 관리자 화면과 숫자가
같습니다.

image::catalog-dashboard/user-dashboard.png[일반 사용자로 본 대시보드 — 관리자와 같은 수치, 900]

대시보드에는 집계 숫자와 데이터셋 이름만 나오고 실제 데이터 값은 나오지 않습니다.

TIP: 대시보드는 화면을 열 때 한 번 통계를 불러옵니다. 다른 화면에서 데이터를 등록 · 동기화한 뒤 최신 값을
보려면 브라우저를 새로 고치거나 다른 메뉴에 갔다가 돌아오세요.

[TIP]
.고급 사용자 — 대시보드 메뉴 닫기 (관리자)
====
관리자가 xref:ops/permissions.adoc[권한 관리] 에서 *대시보드* 메뉴를 닫으면 사이드바에서 메뉴가
숨겨지고, 일반 사용자가 대시보드 주소(`/dashboard`)로 들어오면 *접근 권한 없음* 화면이 나옵니다. 관리자는 항상 볼 수 있습니다.
로그인 직후 첫 화면도 대시보드이므로, 메뉴를 닫을 때는 사용자들이 사이드바에서 다른 메뉴로 이동하면 된다는 점을 미리 안내하세요.
====

== 요약 카드

화면 맨 위에 카드 6개가 있습니다. *삭제됨(removed)* 상태의 데이터셋은 모든 카드와 차트에서 빠집니다.

image::catalog-dashboard/summary-cards.png[요약 카드 6개, 900]

[cols="1,3"]
|===
| 카드 | 의미

| 데이터셋
| 카탈로그에 등록된 데이터셋 수(삭제됨 상태 제외)
| 데이터 소스
| 등록된 데이터 소스 수
| 태그
| 만들어 둔 태그 수
| 용어집
| 용어집의 *용어* 수. 용어를 묶는 분류(폴더)는 세지 않습니다.
| 소유자
| 데이터셋에 지정된 *서로 다른* 소유자 수. 한 사람이 여러 데이터셋의 소유자여도 1명으로 셉니다.
| 동기화 완료
| 데이터 소스의 *메타데이터 동기화* 로 들어온 데이터셋 수. 아래에 "전체 N개 중" 으로 전체 데이터셋 수가 함께 표시됩니다.
|===

NOTE: 화면에서 직접 등록하거나 API 로 등록한 데이터셋은 *데이터셋* 카드에는 더해지지만 *동기화 완료*
에는 들어가지 않습니다. 그래서 두 값의 차이로 수동 등록 데이터셋이 몇 개인지 알 수 있습니다.

== 분포 차트

카드 아래 첫 줄에는 데이터셋이 어디에 얼마나 있는지 보여 주는 차트 3개가 있습니다. 차트 항목에 마우스를
올리면 이름과 값이 툴팁으로 표시됩니다.

[cols="1,3"]
|===
| 차트 | 내용

| 데이터 소스 유형 분포
| 데이터셋 수를 데이터 소스 유형(mysql · postgresql 등)별로 나눈 도넛 차트입니다. 유형이 7개 이상이면 많은 순으로 5개만 보여 주고 나머지는 *기타* 로 묶습니다.
| 환경별 분포
| 데이터셋 수를 환경(DEV · PROD 등)별로 나눈 도넛 차트입니다.
| 데이터셋 수 상위 데이터 소스 (상위 5위)
| 데이터셋이 많은 데이터 소스 5곳을 막대로 보여 줍니다.
|===

image::catalog-dashboard/type-donut-tooltip.png[데이터 소스 유형 분포 — 툴팁, 420]

image::catalog-dashboard/top-datasources-tooltip.png[데이터셋 수 상위 데이터 소스 — 툴팁, 420]

TIP: 막대 차트의 축 이름은 18자를 넘으면 뒷부분을 "..." 로 줄여 표시합니다. 전체 이름은 막대에 마우스를
올리면 툴팁에서 볼 수 있습니다.

NOTE: 이름이 같은 데이터 소스나 데이터셋이 여러 개 있어도 하나로 합치지 않고 각각 따로 막대를 그립니다.
같은 이름의 막대가 두 개 보이면 서로 다른 자산입니다.

== 신규 데이터셋 추이

두 번째 줄에는 새로 등록된 데이터셋 수의 추이를 보여 주는 차트 3개가 있습니다. 시각과 날짜는 *브라우저의
시간대* 기준으로 표시합니다.

[cols="1,3"]
|===
| 차트 | 내용

| 시간별 신규 데이터셋 (최근 24시간)
| 현재 시각을 포함한 최근 24시간을 1시간 단위 막대 24개로 보여 줍니다. 툴팁에는 "11/07 18:00 신규 데이터셋: 2" 처럼 날짜 · 시각과 개수가 표시됩니다.
| 일별 신규 데이터셋 (최근 7일)
| 오늘을 포함한 최근 7일을 날짜별 선 차트로 보여 줍니다.
| 일별 신규 데이터셋 (최근 30일)
| 오늘을 포함한 최근 30일을 날짜별 선 차트로 보여 줍니다.
|===

새 데이터셋이 없던 시간 · 날짜는 *0* 으로 표시되므로, 막대와 점의 간격이 실제 시간 간격과 같습니다.

== 스키마 필드 · 태그 차트

세 번째 줄에는 메타데이터가 얼마나 채워졌는지 보여 주는 차트 2개가 있습니다.

[cols="1,3"]
|===
| 차트 | 내용

화면 맨 아래 표에는 *최근에 수정된 데이터셋 10개* 가 최신순으로 나옵니다.

image::catalog-dashboard/recent-datasets.png[최근 데이터셋 표, 900]

[cols="1,3"]

| 열 | 내용

== 데이터를 추가하면

데이터 소스를 등록하고 데이터셋이 늘어나면, 대시보드를 다시 열었을 때 카드와 차트에 바로 반영됩니다.
아래는 PROD 환경의 데이터 소스와 데이터셋 2개를 직접 등록한 뒤의 화면입니다.

image::catalog-dashboard/after-add.png[데이터 추가 후 — 카드 · 환경별 분포 · 추이 차트 반영, 900]

* *데이터셋* · *데이터 소스* 카드 값이 늘어납니다.
* *환경별 분포* 에 PROD 항목이 새로 생깁니다.
* 직접 등록한 데이터셋은 동기화로 들어온 것이 아니므로 *동기화 완료* 는 그대로이고 "전체 N개 중" 의 N 만 늘어납니다.
* 새 소유자를 지정했다면 *소유자* 카드도 늘어납니다.
* *시간별 신규 데이터셋* 의 현재 시각 막대와 *일별* 차트의 오늘 점이 올라갑니다.

데이터셋을 *삭제됨* 상태로 바꾸면 반대로 카드 · 차트 · 최근 데이터셋 표에서 빠집니다.

== 자주 묻는 질문

[qanda]
차트에 *데이터 없음* · *아직 데이터가 없습니다* 만 보입니다.::
  오류가 아니라 아직 집계할 데이터가 없는 상태입니다. 아래 표를 참고하세요.

데이터를 등록했는데 숫자가 그대로입니다.::
  대시보드는 화면을 열 때 한 번만 통계를 불러옵니다. 브라우저를 새로 고치거나 다른 메뉴에 갔다가 돌아오세요.

*데이터셋* 카드와 *동기화 완료* 카드 값이 다릅니다.::
  화면 · API 로 직접 등록한 데이터셋은 *동기화 완료* 에 들어가지 않습니다. 두 값의 차이가 수동 등록 데이터셋 수입니다.

같은 이름의 막대가 두 개 보입니다.::
  이름이 같아도 서로 다른 자산이면 따로 그립니다.

=== 데이터가 없을 때 · 불러오지 못할 때

아직 데이터가 없는 차트에는 빈 화면 대신 안내 문구가 표시됩니다. 오류가 아니므로 데이터 소스를 등록하고
동기화하면 채워집니다.

image::catalog-dashboard/empty.png[데이터가 없는 대시보드 — 차트별 안내 문구, 900]

[cols="1,2"]
|===
| 영역 | 안내 문구

| 분포 차트 3개
| 데이터 없음
| 신규 데이터셋 추이 3개
| 아직 데이터가 없습니다
| 데이터 소스별 스키마 필드 수
| 스키마 데이터가 없습니다
| 태그 수 상위 데이터셋
| 태그된 데이터셋이 없습니다
| 최근 데이터셋
| 아직 데이터셋이 없습니다
|===

통계를 불러오지 못하면 "통계를 불러오지 못했습니다 (HTTP 상태 코드 또는 네트워크 오류)" 문구와
*다시 시도* 버튼이 표시됩니다. 버튼을 눌러도 계속 실패하면 관리자에게 서버 상태를 확인해 달라고 요청하세요.
