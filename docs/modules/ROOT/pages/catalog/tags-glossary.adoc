= 태그·용어집

데이터셋을 분류하고 비즈니스 용어를 정의하는 데 쓰이는 두 가지 도구를 소개합니다.

태그가 *분류·발견* 을 위한 가벼운 라벨이라면, 용어집은 *조직의 공식 용어 체계* 를
정의하는 계층 구조입니다. 쓰임새가 다르니 상황에 맞게 골라 쓰시면 됩니다.

== 태그

좌측 사이드바 *Governance → Tags* 에서 진입합니다.

=== 태그 생성·수정·삭제

[cols="1,3"]
|===
| 필드 | 설명

| 이름
| 영문 · 한글 · 한자를 모두 쓸 수 있습니다.
| 색상
| 12 색 팔레트에서 고르거나 임의의 헥스 값을 지정합니다. 데이터셋 카드에 배지로 표시됩니다.
| 설명
| 태그의 의도를 적습니다 (선택).
|===

태그를 삭제하면 데이터셋과의 연결도 함께 해제됩니다.

=== 데이터셋에 태그 부여

데이터셋 상세의 *Tags* 탭에서 태그를 검색해 선택합니다. 한 데이터셋에 여러 태그를
부여할 수 있습니다. 부착된 태그는 다음 위치에 즉시 반영됩니다.

* 데이터셋 목록·검색 필터
* xref:ops/alerts.adoc[알림] 규칙의 Scope=TAG 평가

=== CATEGORY / TERM 계층

용어집은 두 단계로 이뤄진 트리입니다.

* *CATEGORY* — 도메인 영역입니다 (예: 고객, 결제, 마케팅). 하위 노드를 가질 수 있습니다.
* *TERM* — 실제 용어입니다 (예: 고객 등급, 결제 수단). 데이터셋·컬럼과 매핑되는 대상입니다.

깊이는 얼마든지 중첩할 수 있지만, *조회 편의를 위해 2~4 단계를 권장합니다*.

=== 용어 등록

각 노드는 다음 정보를 가집니다.

* *이름* — 용어 (예: "고객 등급").
* *정의* — 비즈니스 정의. Markdown 지원.
* *동의어* — 다중 입력. 검색 매칭 폭 확대.
* *연관 데이터셋·컬럼* — 자동 또는 수동 매핑.

=== Move to 기능

트리 노드를 다른 부모로 옮길 수 있습니다. 우클릭 메뉴 → *Move to → \<target>* 또는
드래그-드롭으로 이동하면 됩니다. 하위 트리가 함께 따라 이동하며, 이동한 뒤에도
URN/식별자는 그대로 유지됩니다.

=== 데이터셋·컬럼 매핑

데이터셋 상세의 *Terms* 탭에서 용어를 검색해 매핑합니다. 컬럼 단위 매핑은
스키마 그리드의 *Term* 컬럼에서 부여합니다.

자동 매핑은 xref:catalog/standards.adoc#_자동_매핑[데이터 표준 → 자동 매핑] 에서 일괄 실행
할 수 있다.
