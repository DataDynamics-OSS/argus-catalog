= 스키마

데이터셋 상세의 *Schema* 탭은 컬럼 정의와 변경 이력을 한자리에서 관리하는 곳입니다.
테이블이 어떤 컬럼으로 이뤄져 있고, 그동안 어떻게 바뀌어 왔는지를 여기서 살펴볼 수 있습니다.

== 컬럼 정의

ag-grid 기반 인라인 편집으로, 표 위에서 바로 값을 고칠 수 있습니다. 컬럼별로 다음 속성을 관리합니다.

[cols="1,3"]
|===
| 항목 | 설명

| 이름
| 컬럼 물리명입니다. 동기화 결과로 자동 채워집니다.
| 타입
| 소스 DB 타입을 그대로 반영합니다 (`VARCHAR(20)`, `BIGINT` 등).
| NULL 허용
| boolean 값입니다. PK 컬럼은 자동으로 NOT NULL 이 됩니다.
| 기본값
| DDL 의 DEFAULT 절입니다.
| 설명
| 사용자가 입력하거나 AI 가 자동 생성합니다.
| 용어 매핑
| 표준 용어와 연결합니다. xref:catalog/standards.adoc[데이터 표준] 을 참조해 주세요.
|===

편집한 내용은 *Save* 로 한 번에 반영합니다. 이후 동기화가 값을 다시 덮어쓰지 않도록
*Manual* 플래그가 자동으로 붙습니다.

== 키 제약

PK · Unique · Index 는 컬럼 좌측의 아이콘으로 표시됩니다.

* *PK* — 노란색 열쇠입니다. 복합 키는 동일한 PK 그룹 번호로 묶여 표시됩니다.
* *Unique* — 파란색 U 입니다. 여러 컬럼으로 묶인 Unique 인덱스는 같은 그룹으로 보입니다.
* *Index* — 회색 i 입니다. 검색용 보조 인덱스입니다.

키 정보는 동기화 시 소스 DB 의 `information_schema` 또는 메타 카탈로그에서 수집합니다.

== 변경 이력

image::catalog-schema/history.png[스키마 변경 이력, 800]

동기화하거나 수동으로 편집할 때마다 스냅샷이 생성됩니다. 변경된 부분은 색으로 구분해 보여 줍니다.

* *추가된 컬럼* — 녹색으로 표시됩니다.
* *삭제된 컬럼* — 빨간색으로 표시됩니다.
* *타입 변경* — 노란색으로 표시되며, 이전/이후 값을 모두 보여 줍니다.

스냅샷은 xref:ops/alerts.adoc[알림] 의 영향 분석 입력으로도 사용됩니다.
컬럼 DROP 은 BREAKING, 타입 변경은 WARNING 으로 자동 분류됩니다.
