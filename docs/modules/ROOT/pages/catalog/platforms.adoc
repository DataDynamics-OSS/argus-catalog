= 플랫폼

플랫폼은 데이터가 실제로 살고 있는 시스템을 가리킵니다. MySQL · PostgreSQL 같은 DBMS
부터 Kafka · S3 같은 비정형 저장소까지, 종류가 제각각인 시스템을 단일 카탈로그로
묶어 줍니다.

== 지원 플랫폼

기본으로 20 종의 플랫폼을 제공합니다.

[cols="1,3"]
|===
| 카테고리 | 플랫폼

| 관계형 DBMS
| MySQL, PostgreSQL, Oracle, MSSQL, Greenplum, Snowflake, BigQuery, Redshift
| 분석 엔진
| Hive, Impala, Trino, StarRocks, Kudu
| 메시지 / 스트림
| Kafka
| 스토리지
| S3, HDFS
| 검색 / 문서
| Elasticsearch, MongoDB
| 통합 카탈로그
| Unity Catalog
| 사용자 정의
| Java, Python (코드 자산 등록용)
|===

기본 시드에 없는 신규 플랫폼은 *+ Add Platform* 에서 직접 등록할 수 있습니다.

== 플랫폼 등록

// TODO: screenshot - 플랫폼 등록 폼
image::catalog-platforms/create.png[플랫폼 등록, 800]

다음 정보를 입력합니다.

* *이름* — 사내에서 알아볼 수 있는 이름을 적습니다 (예: `prod-mysql-billing`).
* *종류* — 위 목록에서 선택합니다.
* *연결 설정* — 호스트 · 포트 · 인증을 입력합니다. 종류에 따라 폼이 동적으로 바뀝니다.
* *환경* — 기본 환경 (PROD/STAGING/DEV) 을 지정합니다.

등록한 직후에는 *Test Connection* 으로 연결을 검증해 보시길 권합니다. 인증 비밀번호는
마스킹되어 저장되며, 응답에서는 `••••••••` 으로만 보입니다.

== 메타데이터 동기화

// TODO: screenshot - 동기화 실행 결과 (다이얼로그 또는 토스트)
// image::catalog-platforms/sync.png[메타데이터 동기화, 800]

테이블과 컬럼 정보를 일일이 손으로 옮길 필요 없이, 플랫폼에서 곧장 끌어오는 기능입니다.
MySQL · MariaDB · PostgreSQL 은 자동 메타데이터 수집을 지원하며, 플랫폼 카드의 *Sync*
버튼으로 실행합니다.

수집 대상::
* 모든 데이터베이스 · 스키마 · 테이블 · 뷰
* 각 테이블의 컬럼 (이름 · 타입 · NULL 허용 · 기본값)
* 키 정보 (PK · Unique · Index)
* DDL 원문
* 행 수 추정치
* (옵션) 샘플 데이터 — Parquet 으로 캐시 저장

후처리::
* 데이터셋 신규 등록 또는 기존 데이터셋 업데이트
* 스키마 변경분은 `catalog_schema_snapshots` 에 스냅샷으로 남음
* LLM 자동 생성이 켜져 있으면 빈 설명이 한국어/영어로 자동 채움
* xref:ops/alerts.adoc[알림] 규칙이 활성이면 변경분에 대해 평가

== 환경별 동작

플랫폼은 환경 (`PROD` · `STAGING` · `DEV`) 단위로 동기화 결과를 분리합니다.
같은 호스트라도 환경만 달리해 두 번 등록하면, 두 환경의 데이터셋이 각각 따로 적재됩니다.

== 연결 정보 관리

연결 설정은 *Platform Detail → Configuration* 탭에서 수정합니다.

* 호스트 · 포트를 바꾼 뒤에는 *Test Connection* 으로 다시 검증해 주세요.
* 비밀번호를 바꿀 때 빈 칸으로 두면 기존 값이 그대로 유지됩니다.
* 변경 이력은 시스템 감사 로그에 남습니다.
