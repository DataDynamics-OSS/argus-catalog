= 용어집
:toc: macro
:toclevels: 2

"이탈률"이 팀마다 다른 뜻으로 쓰이면 같은 숫자를 두고도 회의가 길어집니다.
**용어집**은 조직이 쓰는 **비즈니스 용어와 그 정의**를 분류(폴더) 트리로 정리해 두고, 데이터셋과 연결해 "이 데이터가 무엇을 뜻하는지"를 알려 주는 메뉴입니다.

이 문서는 처음 사용하는 분을 기준으로 화면(메뉴) 순서대로 설명합니다.
중간중간 나오는 **고급 사용자** 상자는 몰라도 사용에 지장이 없는 심화 내용이니 처음에는 건너뛰어도 됩니다.

[NOTE]
====
**용어집과 데이터 표준은 다릅니다.** xref:governance/standards.adoc[데이터 표준]의 "표준 용어"는 컬럼 이름·타입 규칙(`cust_no`, `VARCHAR(20)`)이고,
용어집의 "용어"는 사람이 읽는 **업무 정의**("이탈률 = 월간 해지 고객 비율")입니다. 둘은 따로 관리됩니다.
====

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **분류 트리 만들기** — "고객", "물류" 같은 분류 아래에 하위 분류와 용어를 정리합니다.
* **용어 정의** — 용어마다 설명(정의)을 적고, 표에서 바로 고칩니다.
* **정리·이동** — 용어나 분류를 여러 개 골라 다른 분류로 한 번에 옮깁니다.
* **데이터셋 연결** — 데이터셋에 용어를 붙여 "이 데이터는 고객 생애 가치를 담고 있다"고 표시합니다.
* **찾기·공유** — 전역 검색으로 용어를 찾고, 용어 주소(링크)를 동료에게 보냅니다.

=== 먼저 알아 둘 용어

[cols="1,4",options="header"]
|===
| 용어 | 뜻

| 분류
| 용어를 묶는 폴더입니다. 분류 안에 하위 분류를 얼마든지 둘 수 있습니다. 트리에서 폴더 아이콘으로 보입니다.

| 용어
| 실제 비즈니스 용어와 정의입니다. 반드시 어떤 분류 아래에 있거나 최상위에 있으며, **용어 아래에는 아무것도 둘 수 없습니다**.

| 전체 용어
| 트리 맨 위 항목입니다. 누르면 분류와 상관없이 모든 용어가 표에 나옵니다.

| Root (최상위)
| 이동할 때 고르는 "맨 위" 위치입니다.
|===

=== 메뉴 위치

[cols="1,2,3",options="header"]
|===
| 메뉴 | 주소 | 용도

| 거버넌스 → 용어집 | `/dashboard/glossary` | 분류 트리, 용어 표, 추가·이동·삭제
| 데이터셋 상세 → 메타데이터 탭 → 용어집 | `/dashboard/datasets/{id}` | 데이터셋에 용어 연결·해제
|===

=== 누가 무엇을 할 수 있나요

[cols="3,1,1",options="header"]
|===
| 작업 | 일반 사용자 | 관리자

| 트리·용어 보기, 검색, 링크로 열기 | ✓ | ✓
| 분류·용어 추가, 이름·설명 수정, 이동, 삭제 | 기능 권한 `glossary.edit` 에 따름 | ✓
| 데이터셋에 용어 연결·해제 | 기능 권한 `glossary.edit` 에 따름 | ✓
|===

권한이 없으면 **추가**, **용어 추가**, **이동**, 체크박스, 삭제 버튼이 보이지 않고, 표의 설명 칸을 더블클릭해도 편집되지 않습니다.

image::governance-glossary/user-readonly.png[일반 사용자 화면 — 편집 버튼과 체크박스가 없음, 800]

[TIP]
.고급 사용자
====
`glossary.edit` 는 **권한 관리** 메뉴의 기능(FEATURE) 권한입니다. 아무 역할에도 지정하지 않으면 **관리자만** 편집할 수 있고,
특정 역할에 지정하면 그 역할도 용어집을 편집할 수 있습니다.
====

== 화면 구성

**거버넌스 → 용어집** 을 누르면 왼쪽에 **분류 트리**, 오른쪽에 **용어 표**가 나옵니다.

* 트리에서 분류를 누르면 오른쪽 표에 **그 분류 바로 아래의 용어**가 나오고, 표 위에 분류 경로와 설명이 보입니다.
* 분류 이름 옆 숫자는 그 분류 아래(하위 분류 포함)의 용어 수입니다.
* 분류 앞의 ▶ 를 누르면 하위 분류를 펼치고 접습니다.

image::governance-glossary/terms-grid.png[분류 it-고객 을 고른 모습 — 오른쪽에 용어 2건, 800]

== 분류 만들기

=== 최상위 분류

. 트리에서 **전체 용어** 를 고른 상태(아무 분류도 고르지 않은 상태)로 **분류** 옆 **추가** 를 누릅니다.
. **분류 추가** 창에 **이름**과 **설명**을 적고 **생성** 을 누릅니다.

image::governance-glossary/category-add.png[분류 추가 — 최상위에 새 분류, 800]

=== 하위 분류

트리에서 분류를 하나 고른 다음 **추가** 를 누르면, 창에 "\"분류명\" 아래에 새 분류를 추가합니다."라고 나오고 고른 분류 아래에 만들어집니다.
만든 직후 상위 분류가 자동으로 펼쳐져 새 분류가 바로 보입니다.

=== 이름·설명 바꾸기

* **이름** — 트리에서 분류에 마우스를 올리면 연필 아이콘(이름 바꾸기)과 휴지통 아이콘(삭제)이 나타납니다. 연필 아이콘을 누르고 고친 뒤 Enter(또는 ✓)로 저장, Esc(또는 ×)로 취소합니다.
* **설명** — 분류를 고르면 표 위에 설명이 보이고, 옆의 연필 아이콘(분류 설명 편집)으로 고칩니다.

image::governance-glossary/tree-subcategory.png[하위 분류 추가 후 이름 변경, 800]

NOTE: 분류 이름은 용어집 전체에서 하나만 쓸 수 있습니다. 다만 **분류와 용어는 같은 이름을 함께 쓸 수 있습니다**(예: 분류 "이탈"과 용어 "이탈").

== 용어 추가·편집

. 트리에서 용어를 넣을 분류를 고릅니다(고르지 않으면 최상위에 만들어집니다).
. 표 오른쪽 위 **용어 추가** 를 누르고 **이름**과 **설명**(정의)을 적은 뒤 생성합니다.
. 설명은 나중에 표의 **설명** 칸을 더블클릭해 바로 고칠 수 있습니다. 고친 내용은 즉시 저장됩니다.

TIP: 설명에는 계산식·기준·예외를 함께 적어 두세요. 예: "월간 해지 고객 수 ÷ 월초 활성 고객 수. 휴면 고객은 제외."

== 정리하기 — 이동

=== 용어 옮기기

. 표에서 옮길 용어의 체크박스를 고릅니다. 위쪽에 **이동 (N)** 버튼이 나타납니다.
. **이동 (N)** 을 누르고 나타난 분류 트리에서 대상 분류(또는 **Root (최상위)**)를 고릅니다.

image::governance-glossary/move-terms.png[용어 1건 선택 → 이동 (1) → 대상 분류 선택, 800]

=== 분류 옮기기

. 트리에서 옮길 분류 앞의 체크박스를 고릅니다. 트리 위쪽에 **이동** 버튼이 나타납니다.
. **이동** 을 누르고 대상 분류나 **Root (최상위)** 를 고릅니다. 하위 분류와 용어는 함께 따라갑니다.

image::governance-glossary/move-category-root.png[분류를 최상위로 옮긴 결과, 800]

자기 자신이나 자기 하위 분류 아래로는 옮길 수 없어서, 대상 목록에서 처음부터 빠져 있습니다.

image::governance-glossary/move-excludes-self.png[이동 대상 목록 — 자기 자신은 보이지 않음, 800]

== 삭제

* **용어** — 표의 행 끝 휴지통 아이콘(용어 삭제)을 누릅니다. 용어를 지우면 그 용어가 붙어 있던 데이터셋에서도 자동으로 떨어집니다.
* **분류** — 트리에서 분류에 마우스를 올려 휴지통 아이콘을 누르면 확인 창이 뜹니다.

image::governance-glossary/category-delete.png[분류 삭제 확인 창, 800]

안에 하위 분류나 용어가 남아 있는 분류는 지워지지 않습니다. 실수로 많은 용어를 한꺼번에 지우는 일을 막기 위해서입니다.
이때는 "분류를 삭제할 수 없습니다: 용어 1개가 있습니다."처럼 무엇이 남아 있는지 알려 주니, 안의 항목을 먼저 옮기거나 지운 뒤 다시 시도하세요.

image::governance-glossary/category-delete-refused.png[하위 항목이 있어 삭제가 거부된 안내, 800]

== 데이터셋에 용어 연결하기

. 데이터셋 상세의 **메타데이터** 탭을 엽니다.
. **용어집** 줄의 **추가** 를 누르고, "용어 검색..." 칸에 용어 이름을 넣어 고릅니다.
. 붙은 용어는 칩으로 보입니다. 칩의 × 를 누르면 연결이 풀립니다.

image::governance-glossary/dataset-link.png[메타데이터 탭 — 용어집에 '고객 생애 가치' 연결, 800]

데이터셋에는 **용어만** 붙일 수 있고 분류는 붙일 수 없습니다.

== 찾기와 공유

=== 전역 검색

화면 위쪽 검색창에 용어 이름을 넣으면 검색 결과에 **용어**도 함께 나옵니다. 용어를 누르면 용어집 화면에서 그 용어가 열립니다.

image::governance-glossary/global-search.png[전역 검색 결과의 용어, 800]

=== 용어 링크

용어집 주소 뒤에 `?term=<용어 ID>` 를 붙이면 그 용어가 바로 열립니다. 상위 분류가 자동으로 펼쳐지고, 표 위에 경로(예: `it-고객 / it-이탈률`)가 나오며 그 용어 한 줄만 보입니다.
메신저로 동료에게 용어를 알려 줄 때 이 주소를 보내면 됩니다.

image::governance-glossary/deeplink.png[?term= 링크로 연 용어 — 경로와 1행, 800]

[TIP]
.고급 사용자 — 시맨틱 검색
====
임베딩(시맨틱 검색)이 켜져 있으면 용어를 만들거나 고칠 때 용어의 이름·설명이 함께 색인되어, 뜻이 비슷한 말로도 찾을 수 있습니다.
설정은 xref:ops/embedding.adoc[임베딩 운영]을 참고하세요.
====

== 자주 묻는 질문·문제 해결

[qanda]
"같은 이름의 분류(용어)가 이미 있습니다"라고 나옵니다.::
  분류는 분류끼리, 용어는 용어끼리 이름이 겹칠 수 없습니다. 다른 이름을 쓰거나 기존 항목을 쓰세요. 분류와 용어끼리는 같은 이름도 괜찮습니다.

분류를 지울 수 없습니다.::
  안에 하위 분류나 용어가 있습니다. 안내 문구에 남은 개수가 나오니 먼저 옮기거나 지우세요.

원하는 분류가 이동 대상에 없습니다.::
  옮기려는 분류 자신과 그 하위 분류는 대상에서 빠집니다. 그리고 용어 아래로는 옮길 수 없습니다.

방금 만든 하위 분류가 보이지 않습니다.::
  상위 분류는 자동으로 펼쳐집니다. 그래도 안 보이면 상위 분류 앞의 ▶ 를 눌러 펼쳐 보세요.

추가·이동 버튼이 없습니다.::
  용어집 편집 권한(`glossary.edit`)이 없습니다. 관리자에게 요청하세요.

== 부록 — REST API 로 쓰기

기본 경로는 `/api/v1/catalog/glossary` 입니다. 조회 · 변경 모두 로그인 토큰이 필요합니다.

[cols="2,3",options="header"]
|===
| 엔드포인트 | 설명

| `GET /catalog/glossary` | 전체 분류·용어 목록(`parent_id` 로 트리 구성)
| `POST /catalog/glossary` | 분류·용어 생성. `{"name", "description", "term_type": "CATEGORY"\|"TERM", "parent_id"}`
| `PUT·DELETE /catalog/glossary/{id}` | 보낸 필드만 수정(`parent_id: null` 이면 최상위로 이동) / 삭제(하위가 있으면 409)
| `POST·DELETE /catalog/datasets/{id}/glossary/{term_id}` | 데이터셋에 용어 연결·해제
|===

[source,bash]
----
# 분류 '고객' 아래에 용어 만들기
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"name":"이탈률","term_type":"TERM","parent_id":12,"description":"월간 해지 고객 비율"}' \
  "$CATALOG/api/v1/catalog/glossary"
----
