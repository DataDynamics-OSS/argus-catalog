= 태그
:toc: macro
:toclevels: 2

**태그**는 데이터셋에 붙이는 가벼운 색깔 라벨입니다. `PII`, `tier-1`, `deprecated` 처럼 붙여 두면 목록에서 걸러 보기 쉽고,
xref:governance/alerts.adoc[알림] 규칙의 감시 범위로도 쓸 수 있습니다.

이 문서는 처음 사용하는 분을 기준으로 화면(메뉴) 순서대로 설명합니다.
중간중간 나오는 **고급 사용자** 상자는 몰라도 사용에 지장이 없는 심화 내용이니 처음에는 건너뛰어도 됩니다.

[NOTE]
====
**태그와 용어집은 쓰임새가 다릅니다.** 태그는 "분류·검색용 라벨"이라 정의 없이 짧게 붙이고,
xref:governance/glossary.adoc[용어집]은 업무 용어와 그 정의를 트리로 관리합니다. "이 데이터에 개인정보가 있다"는 태그로, "이탈률이란 무엇인가"는 용어집으로 관리하세요.
====

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **태그 만들기** — 이름·설명·색상을 정해 조직 공통 라벨을 만듭니다.
* **데이터셋에 붙이기** — 데이터셋 상세에서 태그를 붙이고 뗍니다. 한 데이터셋에 여러 태그를 붙일 수 있습니다.
* **걸러 보기** — 데이터셋 목록에서 태그로 걸러 봅니다.
* **알림 범위로 쓰기** — "PII 태그가 붙은 모든 데이터셋"처럼 알림 규칙의 감시 대상을 태그로 정합니다.
* **안전하게 지우기** — 지우기 전에 어디에서 쓰이는지 확인합니다.

=== 메뉴 위치

[cols="1,2,3",options="header"]
|===
| 메뉴 | 주소 | 용도

| 거버넌스 → 태그 | `/dashboard/tags` | 태그 카드 목록, 추가·수정·삭제
| 데이터셋 상세 → 메타데이터 탭 → 태그 | `/dashboard/datasets/{id}` | 데이터셋에 태그 붙이기·떼기
|===

=== 누가 무엇을 할 수 있나요

[cols="3,1,1",options="header"]
|===
| 작업 | 일반 사용자 | 관리자

| 태그 목록 보기, 태그로 데이터셋 걸러 보기 | ✓ | ✓
| 태그 추가·수정·삭제, 데이터셋에 태그 붙이기·떼기 | 기능 권한 `tags.manage` 에 따름 | ✓
|===

권한이 없으면 **태그 추가** 버튼과 카드의 연필·휴지통 아이콘 버튼이 보이지 않습니다.

image::governance-tags/user-readonly.png[일반 사용자 화면 — 목록만 보이고 추가·수정·삭제 버튼이 없음, 800]

[TIP]
.고급 사용자
====
`tags.manage` 는 **권한 관리** 메뉴의 기능(FEATURE) 권한입니다. 아무 역할에도 지정하지 않으면 **관리자만** 태그를 관리할 수 있습니다.
====

== 태그 목록

**거버넌스 → 태그** 를 누르면 태그가 카드로 나옵니다. 카드에는 색깔 배지로 된 태그 이름과 설명이 보입니다.

image::governance-tags/list.png[태그 카드 목록, 800]

== 태그 추가

. 오른쪽 위 **태그 추가** 를 누릅니다.
. **이름**과 **설명**(선택)을 적습니다.
. **색상**을 고릅니다. 왼쪽 색상 상자를 누르면 색상 선택기가 열리고, 오른쪽 칸에 `#ef4444` 처럼 색상 코드를 직접 넣어도 됩니다. 맨 오른쪽에 실제 배지 모양이 미리 보입니다.
. **생성** 을 누릅니다.

image::governance-tags/add-dialog.png[태그 추가 — 이름·설명·색상과 배지 미리보기, 800]

색상을 고르지 않으면 기본 파란색(`#3b82f6`)이 됩니다. 색상 코드는 `#` 과 16진수 여섯 자리(`#rrggbb`)만 쓸 수 있으며, 다른 형식을 넣으면 안내가 뜨고 **생성** 버튼이 잠깁니다.

image::governance-tags/color-invalid.png[잘못된 색상 코드 — 형식 안내와 생성 버튼 비활성, 800]

NOTE: 태그 이름은 **대소문자를 구분하지 않고** 하나만 쓸 수 있습니다. `PII` 가 있으면 `pii` 는 만들 수 없습니다.

TIP: 색상에 의미를 정해 두면 한눈에 알아보기 쉽습니다. 예: 빨강 = 민감 정보, 노랑 = 주의·폐기 예정, 초록 = 검증 완료.

== 태그 수정

카드의 연필 아이콘(태그 수정)을 누르면 이름·설명·색상을 고칠 수 있습니다. 이름을 바꿔도 이미 붙어 있는 데이터셋·모델·알림 규칙과의 연결은 그대로 유지됩니다.

image::governance-tags/edit-dialog.png[태그 수정 창, 800]

색상 코드는 대문자로 넣어도 소문자로 저장됩니다(`#FACC15` → `#facc15`).

== 데이터셋에 태그 붙이기

. 데이터셋 상세의 **메타데이터** 탭을 엽니다.
. **태그** 줄("분류·검색용 태그")의 **추가** 를 누르고 "태그 검색..." 칸에서 태그를 고릅니다.
. 붙은 태그는 색깔 칩으로 보입니다. 칩의 × 를 누르면 떨어집니다.

image::governance-tags/dataset-tag.png[메타데이터 탭 — 태그 it-pii 를 붙인 모습, 800]

붙인 태그는 바로 다음 곳에 반영됩니다.

* 데이터셋 목록의 태그 필터
* 태그 범위로 만든 xref:governance/alerts.adoc[알림] 규칙의 감시 대상

[TIP]
.고급 사용자 — 태그로 걸러 보기
====
데이터셋 목록 API 에 `tag` 파라미터를 주면 그 태그가 붙은 데이터셋만 돌려줍니다.

[source]
----
GET /api/v1/catalog/datasets?tag=PII
----
====

== 태그 삭제

카드의 휴지통 아이콘(태그 삭제)을 누르면, 지우기 전에 **이 태그를 쓰는 곳**을 보여 줍니다.

image::governance-tags/delete-usage.png[태그 삭제 — 데이터셋 2개에서 사용 중, 800]

* **데이터셋·OCI 모델에서 사용 중** — 목록을 확인하고 **태그 삭제** 를 누르면, 태그가 지워지면서 그 항목들에서도 자동으로 떨어집니다.
* **알림 규칙이 감시 범위로 사용 중** — 이 경우에는 지울 수 없습니다. 감시 대상이 갑자기 사라지는 것을 막기 위해서입니다. 해당 알림 규칙의 감시 범위를 바꾸거나 규칙을 먼저 지운 뒤 다시 시도하세요.
* 아무 데서도 쓰지 않으면 "안전하게 삭제할 수 있습니다"라고 나옵니다.

== 자주 묻는 질문·문제 해결

[qanda]
"같은 이름의 태그가 이미 있습니다"라고 나옵니다.::
  대소문자만 다른 이름도 같은 태그로 봅니다. 기존 태그를 쓰거나 다른 이름을 고르세요.

생성 버튼이 눌리지 않습니다.::
  색상 코드가 `#rrggbb` 형식이 아닙니다. 색상 상자로 고르거나 `#3b82f6` 처럼 여섯 자리로 넣으세요.

태그를 지울 수 없습니다.::
  알림 규칙이 이 태그를 감시 범위로 쓰고 있습니다. 삭제 창에 나온 규칙의 범위를 바꾸거나 규칙을 먼저 지우세요.

태그 추가·수정 버튼이 없습니다.::
  태그 관리 권한(`tags.manage`)이 없습니다. 관리자에게 요청하세요.

== 부록 — REST API 로 쓰기

기본 경로는 `/api/v1/catalog` 입니다. 목록 조회 · 변경 모두 로그인 토큰이 필요합니다.

[cols="2,3",options="header"]
|===
| 엔드포인트 | 설명

| `GET /catalog/tags` | 태그 목록
| `POST /catalog/tags` | 생성 `{"name", "description", "color"}` (색상 생략 시 `#3b82f6`)
| `PUT /catalog/tags/{id}` | 이름·설명·색상 수정(보낸 필드만)
| `GET /catalog/tags/{id}/usage` | 사용처 — 데이터셋·OCI 모델·알림 규칙
| `DELETE /catalog/tags/{id}` | 삭제(알림 규칙이 감시 중이면 409)
| `POST·DELETE /catalog/datasets/{id}/tags/{tag_id}` | 데이터셋에 태그 붙이기·떼기
| `GET /catalog/datasets?tag=<이름>` | 태그로 데이터셋 걸러 보기
|===

[source,bash]
----
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"name":"PII","description":"개인정보 포함","color":"#ef4444"}' \
  "$CATALOG/api/v1/catalog/tags"
----
