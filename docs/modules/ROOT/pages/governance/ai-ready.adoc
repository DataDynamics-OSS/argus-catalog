= AI-Ready 점검
:toc: macro
:toclevels: 2

**AI-Ready 점검**은 데이터셋마다 행정안전부 · NIA 「공공데이터의 인공지능 친화적 관리 가이드라인」 V1.0(2026-03) 부록 4 체크리스트를
판정해, 어느 데이터셋이 AI 학습 · 분석에 쓸 준비가 되었는지 한눈에 보여 주는 화면입니다.
항목별 판정과 근거, 수동 판정은 데이터셋 상세의 xref:catalog/datasets.adoc#help-dataset-ai-ready-check[AI-Ready 탭] 에서 합니다.

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **전체 현황 보기** — 활성 데이터셋 수, 필수 · 권장 충족률 평균, 필수 항목을 모두 충족한 데이터셋 수, 공유 최소 요건을 충족한 데이터셋 수.
* **범위 좁히기** — 위쪽 줄에서 *카탈로그: 전체* → *DB: 전체* 를 차례로 고르고 검색 칸에 테이블 이름을 넣어 범위를 좁힙니다.
  DB 는 카탈로그를 고른 뒤에 고를 수 있고, 선택지 옆 괄호는 데이터셋 수입니다. 검색어는 입력을 멈추면 바로 반영됩니다.
  걸린 조건은 아래 *조건* 줄에 칩으로 보이고, 칩의 X 나 *모두 지우기* 로 풉니다.
* **카탈로그 · DB 별 비교** — 카탈로그마다 데이터셋 수 · 충족률 평균 · 최소 요건 충족(충족 수 / 데이터셋 수, %)을 보여 줍니다.
  카탈로그 이름을 누르면 그 카탈로그로 좁혀지고 표가 DB 별로 바뀝니다. 제목의 *전체 카탈로그* 를 누르면 돌아갑니다.
  처음에는 5개만 보이고 *모두 보기* 로 펼칩니다. 열 머리를 누르면 정렬합니다(기본: 필수 충족률 낮은 순).
* **먼저 손볼 데이터셋 찾기** — 기본 정렬이 필수 충족률이 낮은 순입니다. *적정이 아닌 필수 항목* 칸은 앞 3개를 "C05 필수 메타데이터"처럼
  번호와 짧은 이름으로, 나머지는 *외 n개* 로 보여 줍니다(마우스를 올리면 점검 내용 · 나머지 목록). 데이터셋 이름을 누르면 상세의 AI-Ready 탭이 열립니다.
* **조건 유지** — 고른 조건 · 정렬 · 쪽은 주소에 남아, 상세에 다녀오거나 주소를 다른 사람에게 보내도 같은 목록이 보입니다.

=== 메뉴 위치

왼쪽 메뉴 **거버넌스 › AI-Ready 점검** (`/dashboard/ai-ready`). 권한 관리에서 메뉴를 닫지 않았으면 누구나 볼 수 있습니다.

== 목록

[cols="1,3",options="header"]
|===
| 칸 | 내용

| 데이터셋
| 데이터셋 목록과 같이 표시 이름이 있으면 표시 이름, 없으면 `DB.테이블` 경로입니다. DB 가 여러 단계면(PostgreSQL 의 `db.schema`) 점으로 이어 보여 줍니다.
  아래 회색 줄에 경로(표시 이름이 있을 때)와 카탈로그 이름(카탈로그를 고르지 않았을 때)이 보입니다.
| 필수 충족률
| 필수 항목(공통 15 + 해당하는 유형별 필수) 가운데 적정 수 ÷ (항목 수 − 해당없음). 괄호 안은 적정 수 / 대상 수입니다.
| 권장 충족률
| 같은 방식으로 권장 항목만 셉니다. 권장 항목은 충족하지 않아도 경고로만 봅니다.
| 최소 요건
| 결측률 · 필수 메타데이터 · 갱신 주기 · 표준 포맷 네 조건을 모두 충족하면 *충족* 입니다. 기준값은 xref:ops/settings.adoc#_ai_ready[설정 › AI-Ready].
| 적정이 아닌 필수 항목
| 미흡이거나 판정 필요인 필수 항목(C01~C33, T2~T4)입니다. 앞 3개는 번호와 짧은 이름, 나머지는 *외 n개* 입니다.
|===

검색어는 `db.dataset` 경로와 표시 이름에서 찾습니다(대소문자 무시). 예를 들어 `sakila.film` 처럼 DB 와 테이블을 함께 적어도 됩니다.
열 머리(*데이터셋* · *필수 충족률* · *권장 충족률*)를 누르면 그 열로 정렬하고, 한 번 더 누르면 반대 순서가 됩니다.
*필수 미충족만* 을 켜면 필수 항목이 하나라도 적정이 아닌 데이터셋만 보입니다. 표 아래에서 쪽을 넘기고 쪽당 행 수(10~50)를 고릅니다.
충족률 색은 100% 초록, 70% 이상 주황, 그 밖 빨강입니다.
상태가 *removed*(원본에서 사라짐)인 데이터셋은 점검하지 않습니다.

[TIP]
.고급 사용자 — 판정 방식
====
자동 판정은 저장하지 않고 화면을 열 때 계산하므로, 메타데이터를 고치거나 품질 진단을 다시 하면 바로 반영됩니다.
수동 판정만 `catalog_ai_ready_judgment` 표에 남습니다. 같은 결과를 API 로도 받을 수 있습니다 —
`GET /api/v1/catalog/ai-ready/overview`(목록 — `catalog_id` · `db` · `q` · `sort` · `desc`), `GET /api/v1/catalog/ai-ready/scopes`(카탈로그 · DB 선택지), `GET /api/v1/catalog/datasets/{id}/ai-ready/check`(데이터셋 하나),
`PUT · DELETE /api/v1/catalog/datasets/{id}/ai-ready/check/{항목 번호}`(수동 판정).
====

== 자주 묻는 질문

**C21(데이터 카드)이 미흡으로 나옵니다.**::
데이터 카드는 Argus 가 자동으로 만들지만, 설명과 *알려진 편향 또는 한계* 가 비어 있으면 용도 · 리스크 요약이 빠지므로 미흡입니다.
메타데이터 탭의 AI 활용 항목을 채우세요. C04(DCAT)는 Argus 가 DCAT · Croissant 를 내보내므로 자동으로 적정입니다
(xref:catalog/datasets.adoc#help-dataset-ai-ready-export[내보내기]).

**C27 · C33 이 판정 필요로 나옵니다.**::
데이터셋 AI-Ready 탭의 xref:catalog/datasets.adoc#help-dataset-distributions[배포본] 에 내려받기 URL(C27) · 체크섬(C33)을 적으면 적정이 됩니다.
포털이 다른 방식으로 제공하면 근거를 적고 수동으로 판정하세요.

**판정 필요는 무엇인가요?**::
카탈로그 정보로 판정할 수 없는 항목입니다(예: 표준 용어에 매핑된 컬럼이 없어 C10 을 볼 수 없음, 재식별 위험 평가 C24).
충족률에서는 적정이 아닌 것으로 셉니다. 정보를 채우거나 담당자가 판정하면 바뀝니다.
