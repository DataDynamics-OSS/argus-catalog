= OCI Model Hub

OCI Model Hub 는 HuggingFace 와 비슷한 느낌의 모델 브라우저에, S3/MinIO 기반의
OCI Manifest 모델 저장소를 더한 공간입니다. 사용하는 프레임워크와 상관없이 모델을
올려 두고, 검색하고, 배포할 수 있습니다.

== 진입 경로

좌측 사이드바의 *Model Catalog → OCI Model Hub* (`/dashboard/oci-hub`) 로 들어갑니다.
관리자라면 *OCI Files* 메뉴를 통해 S3 객체 단위의 파일 브라우저에도 접근할 수 있습니다.

== 모델 브라우저

image::models-oci-hub/browse.png[모델 브라우저, 800]

* *카드 뷰* — 모델당 한 장씩 보여 줍니다. 다운로드 수 · 태그 · README 요약이 함께 나타납니다.
* *필터* — Task (`text-classification`, `image-classification` 등), 프레임워크, 라이선스로 걸러냅니다.
* *검색* — 이름 부분 일치로 찾습니다.

카드를 클릭하면 모델 상세로 이동하며, README 본문, 파일 목록, OCI Manifest 를 확인할 수 있습니다.

== S3 저장 구조

----
model-artifacts/                    ← MinIO 또는 S3 버킷
  {model_name}/
    v{version}/
      model.pkl                     ← 모델 가중치
      config.json                   ← 설정
      tokenizer.json                ← 토크나이저 (HF)
      MLmodel                       ← MLflow 메타데이터 (해당 시)
      conda.yaml / requirements.txt
      manifest.json                 ← finalize 시 자동 생성
----

== OCI Manifest

finalize 시점에 OCI Image Manifest 스펙에 맞춰 `manifest.json` 이 생성됩니다.

[source,json]
----
{
  "schemaVersion": 2,
  "mediaType": "application/vnd.oci.image.manifest.v1+json",
  "config": {
    "mediaType": "application/vnd.argus.model.config.v1+json",
    "digest": "sha256:abc123...",
    "size": 512
  },
  "layers": [
    {
      "mediaType": "application/vnd.argus.model.weights",
      "digest": "sha256:def456...",
      "size": 177230,
      "annotations": {
        "org.opencontainers.image.title": "model.pkl"
      }
    }
  ],
  "annotations": {
    "ai.argus.model.name": "argus.ml.iris_classifier",
    "ai.argus.model.version": "1",
    "ai.argus.model.source": "huggingface:bert-base-uncased"
  }
}
----

모든 파일은 SHA256 digest 로 식별됩니다(content-addressable). 이 digest 는 무결성
검증과 중복 제거에 사용됩니다.

== 업로드 / 다운로드

용량이 큰 파일은 *Presigned URL* 방식을 써서 서버를 거치지 않고 S3 와 직접 주고받습니다.

[cols="1,3"]
|===
| 동작 | 흐름

| 작은 파일 업로드 | `POST /api/v1/model-store/{name}/versions/{ver}/upload` (multipart)
| 큰 파일 업로드 | `POST .../upload-url` 로 Presigned PUT URL 발급 → 클라이언트가 S3 에 직접 PUT
| 단일 파일 다운로드 | `GET .../download-url?filename=X` → Presigned GET URL
| 일괄 다운로드 | `GET .../download-urls` → 모든 파일의 URL 목록
|===

== HuggingFace 임포트

// TODO: screenshot - HF 임포트 다이얼로그
image::models-oci-hub/hf-import.png[HuggingFace 임포트, 800]

온라인 환경이라면 HuggingFace Hub 의 모델을 명령 한 번으로 가져올 수 있습니다.

[source,bash]
----
# CLI
argus-model import-hf bert-base-uncased argus.ml.bert --server http://catalog:4600

# Python SDK
from argus_catalog_sdk import ModelClient
client = ModelClient("http://catalog:4600")
client.import_huggingface("bert-base-uncased", "argus.ml.bert")
----

이때 서버는 내부적으로 다음 작업을 차례대로 수행합니다.

. `huggingface_hub.snapshot_download()` 로 임시 다운로드합니다.
. S3 의 `{model}/v{N}/` 하위에 모든 파일을 업로드합니다.
. `config.json` 에서 `model_type`, `architectures` 등을 추출합니다.
. OCI manifest 를 생성해 저장합니다.
. DB 에 메타데이터를 기록합니다.

== Airgap 임포트

// TODO: screenshot - airgap 임포트 절차 (다이어그램 또는 단계 카드)
image::models-oci-hub/airgap-import.png[Airgap 임포트, 800]

인터넷이 막힌 폐쇄망에서는 다음 2 단계로 진행합니다.

. *온라인 환경* — 모델을 다운로드한 뒤 USB 나 파일로 전송합니다.
+
[source,bash]
----
argus-model import-hf bert-base-uncased argus.ml.bert --server http://online-catalog:4600
argus-model pull argus.ml.bert 1 /usb/bert-export/
----

. *Airgap 환경* — 서버가 접근할 수 있는 경로에 파일을 옮긴 다음 import 합니다.
+
[source,bash]
----
argus-model import-local /data/transferred/bert argus.ml.bert \
  --server http://airgap-catalog:4600
----

그러면 서버가 로컬 디렉토리를 스캔해 S3 에 업로드하고, manifest 를 생성합니다.

== 다운로드 추적

`/api/v1/oci-models/{name}` 의 *download_count* 와 다운로드 로그는 자동으로 누적됩니다.
모델 상세 화면에서 시간대별 다운로드 추이를 확인할 수 있습니다.
