= 백엔드 API 플러그인 만들기

고객사 전용 API 가 필요하면 *별도 pip 패키지* 로 FastAPI 라우터를 만들어
`argus.plugins` entry point 에 등록합니다. 코어(`backend/app/`)는 전혀 수정하지 않습니다.
서버 기동 시 코어가 자동으로 발견·등록하며 경로는 `/api/v1/<...>` 가 됩니다. 화면에서
호출할 데이터 API 를 이렇게 만들어 보겠습니다.

== 위치

기존 `extensions/` 컨벤션을 그대로 따릅니다.

[source,text]
----
extensions/argus-plugin-<고객사>/
├── pyproject.toml
└── src/argus_plugin_<고객사>/
    ├── __init__.py     # `plugin` 객체 export (router 보유)
    └── router.py       # FastAPI APIRouter
----

== 플러그인 계약

코어 로더(`backend/app/plugins.py`)는 entry point 를 로드해 그 객체의 *`router`
속성* 을 본체 앱에 등록합니다. 로더가 기대하는 속성은 다음과 같습니다.

[cols="1,1,3"]
|===
| 속성 | 필수 | 의미

| `router` | 필수 | FastAPI `APIRouter`
| `prefix` | 선택 | 라우터 등록 prefix. 미지정 시 `/api/v1`
|===

== 3단계로 추가하기

라우터를 만들고, export 하고, entry point 로 선언하는 세 단계면 됩니다.

=== 1. 라우터 작성 (`router.py`)

[source,python]
----
# SPDX-License-Identifier: Apache-2.0
from fastapi import APIRouter

router = APIRouter(prefix="/acme", tags=["acme-plugin"])


@router.get("/billing/summary")
def billing_summary() -> dict:
    # 실제로는 고객 DB/서비스를 조회한다.
    return {"month_total": 12_400_000, "currency": "KRW", "unsettled_count": 37}
----

코어가 `/api/v1` prefix 로 등록하므로 최종 경로는 `/api/v1/acme/billing/summary` 입니다.

=== 2. `plugin` 객체 export (`__init__.py`)

[source,python]
----
from types import SimpleNamespace
from .router import router

# 로더가 참조하는 객체. router 필수, prefix 선택(미지정 시 /api/v1).
plugin = SimpleNamespace(router=router)
----

=== 3. entry point 선언 (`pyproject.toml`)

[source,toml]
----
[project]
name = "argus-plugin-acme"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = ["fastapi>=0.100"]

# 코어가 발견하는 확장 지점. "<모듈>:<속성>" — 속성은 router 를 가진 객체.
[project.entry-points."argus.plugins"]
acme = "argus_plugin_acme:plugin"

[tool.setuptools.packages.find]
where = ["src"]
----

== 설치 & 활성화

=== 설치

플러그인은 고객사 이미지/환경에만 설치합니다.

[source,bash]
----
pip install -e extensions/argus-plugin-acme   # 개발
# 또는 빌드한 wheel 을 고객 이미지에 포함
----

=== 활성화 제어 (`plugins.enabled`)

`config.yml` 의 `plugins.enabled` 로 어떤 플러그인을 켤지 제어합니다.

[cols="1,3"]
|===
| 값 | 동작

| (미설정 / 빈 목록) | 설치되어 *발견된 플러그인을 모두* 로드
| `acme,beta` | 이름이 목록에 *포함된 것만* 로드(나머지는 건너뜀)
|===

[source,yaml]
----
plugins:
  enabled: acme        # 쉼표 구분. 비워두면 설치된 전부 로드
----

[NOTE]
`enabled` 는 *발견된 것 중 무엇을 켤지* 의 필터입니다. 애초에 설치하지 않은 플러그인은
어떤 값을 줘도 로드되지 않습니다.

== 실패 격리 & 우선순위

플러그인이 코어를 방해하지 않도록, 로더는 다음과 같이 동작합니다.

* 한 플러그인의 로드/등록 실패는 *서버 기동과 다른 플러그인* 에 영향을 주지 않습니다(로그만 남깁니다).
* 플러그인 라우터는 코어 라우터 *등록 뒤* 에 붙습니다 → 경로가 충돌하면 코어가 우선합니다.
* `router` 속성이 없는 entry point 는 경고 로그를 남기고 건너뜁니다.

== 인증

플러그인 엔드포인트도 코어와 동일한 인증 의존성을 사용해야 합니다. 코어의 인증
의존성(현재 사용자/관리자 가드)을 라우트에 주입해 보호합니다. 사내망 전제가 아니라면
인증 없는 엔드포인트를 노출하지 않도록 주의하세요.

== 검증

마지막으로 다음 명령으로 라우터가 정상 등록됐는지 확인합니다.

[source,bash]
----
# 구문/임포트
python -m py_compile extensions/argus-plugin-acme/src/argus_plugin_acme/*.py

# 기동 후 등록 확인
curl -s localhost:4600/api/v1/acme/billing/summary
# 서버 로그: "플러그인 'acme' 등록 완료 (prefix=/api/v1)"
----

== 예시

동작하는 전체 예시는 `extensions/argus-plugin-acme/` 를 참고하세요(프론트
`plugins/acme/` 의 정산 화면과 짝을 이룹니다).
