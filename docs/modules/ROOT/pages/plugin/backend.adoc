= 백엔드 API 플러그인 만들기

고객사 전용 API 가 필요하면 *별도 pip 패키지* 로 FastAPI 라우터를 만들어
`argus.plugins` entry point 에 등록합니다. 코어(`backend/app/`)는 전혀 수정하지 않습니다.
서버 기동 시 코어가 자동으로 발견·등록하며 경로는 `/api/v1/<...>` 가 됩니다. 화면에서
호출할 데이터 API 를 이렇게 만들어 보겠습니다.

전체적으로는 서버가 기동할 때 코어 로더가 플러그인 라우터를 등록하고, 이후 요청이
코어 라우터를 거쳐 플러그인 핸들러로 전달됩니다.

== 위치

기존 `extensions/` 컨벤션을 그대로 따릅니다.

[source,text]
----
extensions/argus-plugin-<고객사>/
├── pyproject.toml
└── src/argus_plugin_<고객사>/
    ├── __init__.py     # `plugin` 객체 export (router 보유)
    └── router.py       # FastAPI APIRouter
----

== 플러그인 계약

코어 로더(`backend/app/plugins.py`)는 entry point 를 로드해 그 객체의 *`router`
속성* 을 본체 앱에 등록합니다. 로더가 기대하는 속성은 다음과 같습니다.

[cols="1,1,3"]
|===
| 속성 | 필수 | 의미

| `router` | 필수 | FastAPI `APIRouter`
| `prefix` | 선택 | 라우터 등록 prefix. 미지정·`None`·빈 문자열이면 `/api/v1`
|===

== 3단계로 추가하기

라우터를 만들고, export 하고, entry point 로 선언하는 세 단계면 됩니다.

=== 라우터 작성 (`router.py`)

[source,python]
----
# SPDX-License-Identifier: Apache-2.0
from fastapi import APIRouter, Depends

from app.core.auth import get_current_user

# 라우터 전체에 코어와 같은 인증(현재 사용자 가드)을 건다.
router = APIRouter(
    prefix="/acme",
    tags=["acme-plugin"],
    dependencies=[Depends(get_current_user)],
)


@router.get("/billing/summary")
def billing_summary() -> dict:
    # 실제로는 고객 DB/서비스를 조회한다.
    return {"month_total": 12_400_000, "currency": "KRW", "unsettled_count": 37}
----

코어가 `/api/v1` prefix 로 등록하므로 최종 경로는 `/api/v1/acme/billing/summary` 입니다.

=== `plugin` 객체 export (`__init__.py`)

[source,python]
----
from types import SimpleNamespace
from .router import router

# 로더가 참조하는 객체. router 필수, prefix 선택(미지정 시 /api/v1).
plugin = SimpleNamespace(router=router)
----

=== entry point 선언 (`pyproject.toml`)

[source,toml]
----
[project]
name = "argus-plugin-acme"
version = "0.5.0"
requires-python = ">=3.11"
dependencies = ["fastapi>=0.100"]

# 코어가 발견하는 확장 지점. "<모듈>:<속성>" — 속성은 router 를 가진 객체.
[project.entry-points."argus.plugins"]
acme = "argus_plugin_acme:plugin"

[tool.setuptools.packages.find]
where = ["src"]
----

== 인증

플러그인 엔드포인트도 코어와 동일한 인증 의존성을 사용해야 합니다. 플러그인은 코어
프로세스 안에서 로드되므로 코어의 의존성을 그대로 import 해 쓸 수 있습니다.

[cols="1,3"]
|===
| 의존성 | 용도

| `app.core.auth.get_current_user` | 로그인 사용자만 허용 — 라우터 `dependencies` 에 걸어 기본값으로 사용
| `app.core.auth.require_admin` | 관리자 전용 엔드포인트
| `app.permissions.router.require_feature("<key>")` | 권한 매트릭스의 기능 권한으로 통제
|===

프론트 메뉴를 숨기는 것만으로는 접근을 막을 수 없습니다. 실제 보호는 반드시 API 에서
이뤄져야 하며, 인증 없는 엔드포인트를 노출하지 않도록 주의하세요.

== 검증

개발 중에는 다음 명령으로 구문 오류부터 확인합니다.

[source,bash]
----
python -m py_compile extensions/argus-plugin-acme/src/argus_plugin_acme/*.py
----

설치·활성화 방법은 xref:plugin/configuration.adoc[플러그인 설정·배포] 에서, 기동 후 등록
확인과 로그 해석은 xref:plugin/usage.adoc[플러그인 사용·운영] 에서 다룹니다.

== 예시

동작하는 전체 예시는 `extensions/argus-plugin-acme/` 를 참고하세요(프론트
`plugins/acme/` 의 정산 화면과 짝을 이룹니다).
