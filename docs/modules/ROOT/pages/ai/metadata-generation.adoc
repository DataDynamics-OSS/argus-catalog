= AI 메타데이터 자동 생성
:toc: macro
:toclevels: 2

데이터셋마다 설명을 일일이 손으로 채우는 일은 번거롭습니다. 이 기능은 LLM 으로
데이터셋의 *요약 · 테이블 설명 · 컬럼 설명 · 태그 · PII* 를 자동으로 생성해 줍니다.
결과는 미리 보고 확인한 뒤 반영합니다.

이 페이지는 카탈로그 서버에 내장된 생성 기능을 다룹니다. 서버 밖에서 대량 · 주기적으로 생성하려면
xref:ai/ai-service.adoc[AI 서비스] 의 enrich 를 사용하세요. 결과는 같은 AI 제안으로 들어옵니다.
API · 응답 형식 · 내부 동작은 xref:ai/metadata-generation-advanced.adoc[AI 메타데이터 자동 생성 — 고급] 에 따로 모았습니다.

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **요약 생성** — 데이터셋의 한 줄 요약을 만듭니다.
* **설명 생성** — 테이블의 목적 · 내용을 설명하는 글을 만듭니다.
* **컬럼 설명 생성** — 모든 컬럼의 용도를 한 번에 채웁니다.
* **태그 추천** — 기존 태그를 활용하고 새 태그도 제안합니다.
* **PII 감지** — 개인정보가 담긴 컬럼을 찾아 근거와 함께 알려 줍니다.
* **일괄 생성 · 자동 생성** — 설명이 빈 데이터셋을 한꺼번에, 또는 동기화가 끝날 때마다 채웁니다.

=== 먼저 알아 둘 용어

[cols="1,4",options="header"]
|===
| 용어 | 뜻

| LLM 프로바이더
| 생성을 맡는 언어 모델 서비스입니다. Ollama (로컬), OpenAI, Anthropic (Claude) 를 지원합니다.

| 미리보기
| 생성 결과를 반영하기 전에 확인하는 창입니다. *적용* 을 눌러야 실제로 반영됩니다.

| AI 제안
| 바로 반영하지 않고 남겨 둔 생성 결과입니다. 나중에 적용하거나 거절할 수 있습니다.
|===

=== 메뉴 위치

[cols="1,3",options="header"]
|===
| 메뉴 | 용도

| 설정 → LLM / AI | 기능 켜기, LLM 연결, AI 일괄 생성
| 데이터셋 상세 → 우측 상단 `⋯` (작업) → AI 자동 생성 | 데이터셋 하나에 대해 생성
| 데이터셋 상세 → 우측 상단 *AI 제안* (대기 건수 배지) | 적용하지 않은 제안 검토 · 승인 · 거절 (대기 제안이 있을 때만 보임)
|===

=== 누가 무엇을 할 수 있나요

[cols="3,2",options="header"]
|===
| 작업 | 할 수 있는 사람

| LLM 설정, AI 일괄 생성 | 관리자
| 데이터셋 하나에 대해 생성 · 적용 | 기능 권한 *AI 메타데이터 생성*(`ai.generate`)이 있고, 그 데이터셋의 편집 권한(생성자 또는 관리자)이 있는 사람
| AI 제안 승인 · 거절 | 그 데이터셋의 편집 권한(생성자 또는 관리자)이 있는 사람. 기능 권한 `ai.generate` 는 필요 없습니다.
|===

== LLM 연결하기 (관리자)

기능을 쓰기 전에 어떤 LLM 을 어떻게 연결할지 설정합니다.
xref:ops/settings.adoc#_llm[설정 → LLM / AI] 에서 다음 순서로 진행합니다.

. *AI 메타데이터 생성 활성화* 토글을 켭니다.
. 제공자 · 모델 · API Key · API URL · 생성 언어를 지정합니다.
. *연결 테스트* 로 연결을 확인한 뒤 *저장* 합니다.

image::ai-metadata-generation/ai-setting.png[설정 → LLM / AI, 800]

어떤 LLM 을 고를지는 환경에 따라 정합니다. 외부로 데이터를 보낼 수 없는 환경이라면 로컬 Ollama 를,
더 높은 품질이 필요하다면 클라우드 API 를 선택합니다.

[cols="1,2,3,3",options="header"]
|===
| 프로바이더 | 기본 모델 | API URL | 특성

| `ollama` | `qwen2.5:7b` | `http://localhost:11434` | 로컬 실행. API 키 불필요. 한국어 우수. 에어갭 가능.
| `openai` | `gpt-4o-mini` | `https://api.openai.com/v1` | 클라우드 API. 고품질. API 키 필요.
| `anthropic` | `claude-sonnet-4-...` | `https://api.anthropic.com` | 클라우드 API. 고품질. API 키 필요.
|===

[TIP]
.고급 사용자 — Ollama 설치와 권장 모델
====
Ollama 를 설치하고 모델을 내려받는 과정은 다음과 같습니다.

[source,bash]
----
curl -fsSL https://ollama.ai/install.sh | sh
ollama pull qwen2.5:7b
ollama list
curl http://localhost:11434/api/tags
----

[cols="2,1,1,3",options="header"]
|===
| 모델 | 크기 | 한국어 | 권장 용도

| `qwen2.5:7b` | 4.4 GB | 우수 | *한국어 메타데이터 기본 권장*
| `qwen2.5:14b` | 8.7 GB | 우수 | 한국어 고품질 (RAM 16 GB+)
| `llama3.1:8b` | 4.7 GB | 보통 | 범용 영문
| `gemma2:9b` | 5.4 GB | 보통 | 다국어
| `EEVE-Korean-10.8B` | 6.5 GB | 최우수 | 한국어 특화
|===

설정 항목 전체와 API 로 설정하는 방법은 xref:ai/metadata-generation-advanced.adoc#_설정_api[고급 — 설정 API] 를 보세요.
도메인 용어까지 정확히 담고 싶다면 xref:ai/fine-tuning.adoc[Fine-tuning 가이드] 를 참고하세요.
====

== 데이터셋 하나에 대해 생성하기

. 데이터셋 상세 화면 우측 상단의 `⋯` (작업) 버튼을 누릅니다. 데이터셋 소유자 또는 관리자에게만 보입니다.
. 메뉴의 *AI 자동 생성* 아래에서 원하는 기능을 고릅니다 — *요약 생성* / *설명 생성* / *컬럼 설명 생성* / *태그 추천* / *PII 감지*.
. 생성하는 동안 진행 창이 뜨고, 끝나면 결과 미리보기 창(*AI 생성 요약* · *AI 생성 설명* · *AI 생성 컬럼 설명* · *AI 추천 태그* ·
  *AI PII 감지 결과*)이 열립니다.
. 결과를 확인한 뒤 *적용* 을 누르면 반영되고, *닫기* 를 누르면 반영하지 않습니다. 컬럼 설명은 *전체 적용 (N)*,
  태그 · PII 는 *적용 (N)* 처럼 반영할 개수가 버튼에 표시됩니다.

image::ai-metadata-generation/preview-dialog.png[AI 생성 컬럼 설명 미리보기, 900]

LLM 이 꺼져 있으면 메뉴는 보이지만 누를 수 없고, 기능 권한 *AI 메타데이터 생성* (`ai.generate`) 이 없으면 메뉴가 숨겨집니다.

[TIP]
.고급 사용자 — 생성 품질을 좌우하는 정보
====
서버는 테이블 · 컬럼 정보, DDL, 샘플 데이터(최대 5행), 표준 단어, 상 · 하류 데이터셋, 이전 생성 예시를
모아 프롬프트에 함께 보냅니다. 표준 사전에 단어를 잘 정리해 두면 약어 해석이 좋아집니다.
자세한 내용은 xref:ai/metadata-generation-advanced.adoc#_프롬프트_컨텍스트[고급 — 프롬프트 컨텍스트] 를 보세요.
====

== 여러 데이터셋을 한 번에 생성하기 (관리자)

데이터셋이 많다면 일괄 생성을 씁니다.

. *설정 → LLM / AI* 화면 아래의 *AI 일괄 생성* 카드로 갑니다.
. *설명 생성* 또는 *전체 생성 (설명 + 컬럼 + 태그 + PII)* 을 누릅니다.

설명이 비어 있는 데이터셋만 처리되며, 결과는 미리보기 없이 즉시 적용됩니다. 요약은 일괄 생성 대상이 아닙니다.
특정 데이터 소스만 처리하는 등 세부 조건은 xref:ai/metadata-generation-advanced.adoc#_일괄_생성_api[고급 — 일괄 생성 API] 로 지정합니다.

== 동기화 후 자동으로 채우기

`설정 → LLM / AI` 에서 *동기화 시 자동 생성*(`auto_generate_on_sync`)을 켜고 저장하면, 메타데이터 동기화가 끝난 뒤 비어 있는
설명을 백그라운드에서 자동으로 채워 줍니다. 자세한 내용은
xref:catalog/platforms.adoc#_메타데이터_동기화[플랫폼 → 메타데이터 동기화] 를 참조하세요.

[[_제안_검토]]
== 제안을 나중에 검토하기

미리보기 창에서 *닫기* 로 넘긴 결과와 xref:ai/ai-service.adoc[AI 서비스] enrich 가 반입한 결과는 *AI 제안* 으로
남아 승인을 기다립니다. 데이터셋 상세에서 하나씩 보고 승인하거나 거절합니다.

. 데이터셋 상세 화면 제목 오른쪽, 상태 배지 옆의 *AI 제안* 버튼을 누릅니다. 버튼의 숫자가 대기 중인 제안 수입니다.
  대기 제안이 없거나 그 데이터셋의 편집 권한(생성자 또는 관리자)이 없으면 버튼이 보이지 않습니다.
. *AI 제안* 창의 표에서 각 제안을 확인합니다.
+
[cols="1,3",options="header"]
|===
| 열 | 내용

| 유형 · 대상 | *요약* · *설명* · *컬럼 설명* · *태그* · *PII* 와 적용 대상(데이터셋 또는 컬럼 이름)
| 제안값 | AI 가 만든 값. 태그는 이름 목록(새로 만들 태그에는 "(새 태그)"), PII 는 `컬럼: 유형` 목록
| 현재 값 | 승인하면 바뀔 지금 값. 비어 있으면 "(없음)"
| 출처 · 시각 | *AI 서비스(enrich)* 또는 *카탈로그 AI 생성*(화면 미리보기), 모델 이름과 생성 시각
|===
. 행 오른쪽의 *승인* 을 누르면 바로 반영되고, *거절* 을 누르면 제안이 지워집니다.
  여러 건을 한 번에 반영하려면 왼쪽 확인란으로 고른 뒤(머리글 확인란은 전체 선택) *선택 승인 (N)* 을 누릅니다.
. 승인하면 데이터셋 화면이 새로 고쳐지고, 처리한 제안은 목록에서 빠집니다. 남은 제안이 없으면 창과 버튼이 사라집니다.

같은 대상에 제안이 여러 건이면 "같은 대상 제안 여러 건" 표시가 붙습니다. 하나만 승인하고 나머지는 거절하세요
(여러 건을 승인하면 나중에 승인한 값이 남습니다). PII 를 승인하면 해당 컬럼의 PII 유형이 바뀌고,
태그를 승인하면 없는 태그는 새로 만들어 붙입니다.

[TIP]
.고급 사용자 — 스크립트로 처리하기
====
화면과 같은 동작을 REST API(`GET /api/v1/ai/datasets/{id}/suggestions`, `POST /api/v1/ai/suggestions/{id}/apply` · `/reject`,
`POST /api/v1/ai/suggestions/apply-batch`)로도 할 수 있습니다. 자세한 내용은
xref:ai/metadata-generation-advanced.adoc#_제안_관리[고급 — 제안 관리] 를 보세요.
====

== 자주 묻는 질문

*Q. AI 자동 생성 메뉴가 회색으로 눌리지 않습니다.* +
A. LLM 이 꺼져 있습니다. 관리자에게 `설정 → LLM / AI` 의 *AI 메타데이터 생성 활성화* 를 요청하세요.

*Q. 작업 메뉴(`⋯`)나 AI 자동 생성 메뉴가 아예 보이지 않습니다.* +
A. `⋯` 버튼은 데이터셋 소유자 또는 관리자에게만 보이고, AI 자동 생성 메뉴는 기능 권한 *AI 메타데이터 생성*(`ai.generate`)이 있어야 보입니다.

*Q. AI 서비스로 생성했는데 AI 제안 버튼이 보이지 않습니다.* +
A. 버튼은 대기 중인 제안이 있고, 그 데이터셋의 생성자 또는 관리자일 때만 보입니다. enrich 가 `ARGUS_AI_MODE=apply` 로 돌았다면
설명은 제안 없이 바로 적용됩니다.

*Q. 생성 결과가 우리 회사 용어를 잘 모릅니다.* +
A. 데이터 표준 사전에 단어(약어)를 등록하면 프롬프트에 함께 들어가 품질이 좋아집니다. 더 나아가려면 xref:ai/fine-tuning.adoc[Fine-tuning 가이드] 를 참고하세요.

*Q. 데이터가 외부로 나가면 안 됩니다.* +
A. 로컬 Ollama 프로바이더를 쓰세요. API 키가 필요 없고 에어갭 환경에서도 동작합니다.
