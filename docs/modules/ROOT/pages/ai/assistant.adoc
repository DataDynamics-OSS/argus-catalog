= AI 어시스턴트
:toc: macro
:toclevels: 2

AI 어시스턴트는 카탈로그와 대화하듯 질문할 수 있는 채팅 도우미입니다.
아는 내용으로만 답하지 않고, 카탈로그 검색 · 스키마 · ERD · 품질 · 리니지 · 표준 · SQL 작성 같은
도구를 직접 호출해서 **실데이터를 근거로** 답합니다.

toc::[]

== 시작하기 전에

=== 이런 일을 할 수 있습니다

* **데이터 찾기** — "고객 테이블 뭐 있어?"처럼 물어 카탈로그/데이터셋을 검색합니다.
* **구조 확인** — 스키마와 ER 다이어그램(조인 경로)을 물어봅니다.
* **품질 · 리니지 확인** — 데이터 품질과 원천 · 영향 범위를 조회합니다.
* **표준 확인** — 데이터 표준 준수 여부를 조회합니다.
* **SQL 작성 보조** — 조인 근거를 바탕으로 SQL 작성을 돕습니다.

=== 메뉴 위치

* **화면 우하단의 어시스턴트 버튼** — 채팅 창을 엽니다.
* **설정 → AI 어시스턴트** — 관리자가 어시스턴트를 켜고 AI 서비스 URL 을 지정합니다.

=== 누가 무엇을 할 수 있나요

어시스턴트 버튼은 **AI 서비스 기반 어시스턴트 활성화** 가 켜져 있고, 사용자에게
기능 권한 *AI 어시스턴트 사용*(`ai.assistant`)이 있을 때만 보입니다. 이 권한은 기본으로 모든 역할에
허용되며, 권한 관리 화면에서 역할별로 막을 수 있습니다. 채팅 API 도 같은 권한을 검사합니다.

어시스턴트는 사용자의 인증 토큰을 그대로 전달하므로, 도구는 **사용자 권한**으로 동작합니다.
즉 사용자가 볼 수 없는 데이터는 어시스턴트도 보지 못합니다.

== 어시스턴트에게 질문하기

. 화면 우하단의 어시스턴트 버튼을 누릅니다.
. 궁금한 것을 자연스러운 문장으로 입력합니다.
. 어시스턴트가 필요한 도구를 호출한 뒤, 그 결과를 근거로 답을 보여 줍니다.

== 어시스턴트 켜기 (관리자)

도구를 호출하는 답변을 받으려면 xref:ai/ai-service.adoc[AI 서비스] 를 연결해야 합니다. 다음 순서로 설정합니다.

. AI 서비스의 assistant 를 띄웁니다 (`argus-catalog-ai assistant --port 8930`, 패키지 설치 시 `argus-catalog-ai-assistant` 서비스). AI 서비스는 로컬 LLM(ollama 등) 또는 OpenAI 호환 엔드포인트에 연결합니다.
. `설정 > AI 어시스턴트` 탭에서 **AI 서비스 기반 어시스턴트 활성화** 를 켭니다.
. **AI 서비스 URL** (예: `http://<호스트>:8930`)을 넣고 연결 테스트 후 저장합니다.

설치 · 설정 · 도구 목록은 xref:ai/ai-service.adoc[AI 서비스] 를 참고하세요.

[NOTE]
====
AI 서비스의 assistant 는 자신을 xref:governance/ai-agent-catalog.adoc[AI Agent 카탈로그]
에 등록하고 호출 지표를 보고할 수 있습니다. LLM 제공자 구성은
xref:ai/metadata-generation.adoc[메타데이터 자동 생성] 과 공유합니다.
====

[TIP]
.고급 사용자 — 두 가지 동작 모드와 처리 흐름
====
AI 어시스턴트는 두 가지 모드로 동작합니다.

* **AI 서비스 연동(tool-use)** — `설정 > AI 어시스턴트` 에서 활성화하고 AI 서비스 URL 을
  지정하면, 별도로 띄운 xref:ai/ai-service.adoc[AI 서비스] 의 assistant 서버로 프록시하여 도구를 호출하는 답변을 제공합니다.
* **내장 단순 대화(폴백)** — 활성화했지만 AI 서비스 URL 을 지정하지 않았으면 `설정 > LLM / AI` 의 LLM 제공자를 통한 단순 대화로 폴백합니다.

AI 서비스 모드에서 한 번의 질문이 답변으로 이어지는 흐름은 다음과 같습니다.
LLM 이 질문을 보고 어떤 도구를 호출할지 스스로 판단한 뒤, 그 결과를 근거로 답변을 구성합니다.

== 자주 묻는 질문

*Q. 어시스턴트 버튼이 보이지 않습니다.* +
A. 관리자가 `설정 > AI 어시스턴트` 에서 **AI 서비스 기반 어시스턴트 활성화** 를 켰는지, 내 역할에 *AI 어시스턴트 사용*(`ai.assistant`) 권한이 있는지 확인하세요.

*Q. 데이터를 조회하지 않고 일반적인 답만 합니다.* +
A. AI 서비스 URL 이 지정되지 않아 내장 단순 대화로 동작하는 상태입니다. 관리자에게 AI 서비스 연결을 요청하세요.

*Q. 어떤 데이터셋은 어시스턴트가 찾지 못합니다.* +
A. 어시스턴트는 내 권한으로 동작합니다. 내가 볼 수 없는 데이터는 어시스턴트도 보지 못합니다.
